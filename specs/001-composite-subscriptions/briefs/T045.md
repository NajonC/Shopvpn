## Interfaces

These match T044's accepted routine API choices:
- `SecretError(ValueError)`: sanitized failure boundary; messages must contain no input secrets and formatted exceptions must not expose a secret-bearing chained library exception. Use explicit exception suppression where wrapping errors.
- Frozen dataclass `EncryptedValue(version: int, key_id: str, nonce: bytes, ciphertext: bytes)`; no plaintext retained or shown in repr.
- `SecretBox(keys: dict[str, bytes], current_key_id: str)`: explicitly injected authorized keys, copied into private storage; validate configured AES keys (16/24/32 bytes) and active key presence. Never generate a fallback key, read a real config, or print keys.
- `encrypt(plaintext: str) -> EncryptedValue`: version 1, current key ID, cryptographically random fresh 12-byte nonce, AES-GCM ciphertext including tag. AAD exactly `b"shopvpn:secrets:v1:" + key_id.encode("utf-8")`. Accept empty/Unicode strings. Sanitize library/encoding errors.
- `decrypt(value: EncryptedValue) -> str`: use stored key ID (old keys remain readable), same AAD; reject unsupported version, absent/wrong key and tampered nonce/ciphertext/ID with SecretError. Sanitize library/decoding errors.
- `token_digest(token: str) -> str`: lowercase 64-character SHA-256 hex over exact UTF-8 input; no stripping/normalization or token issuance in this task.
- `SecretRedactionFilter(logging.Filter).filter(record: logging.LogRecord) -> bool`: retain severity and standard logging metadata plus trusted `operation`, `tenant_id`, `record_id`; discard free-text message/args, exc_info, exc_text, stack_info, formatter-cached message, and arbitrary extras. Return True so useful sanitized records remain visible. Do not stringify incoming secrets to recognize them. Structured identifiers are trusted inputs, not arbitrary user payloads.
- `install_log_redaction(logger: logging.Logger) -> None`: idempotently add the filter to this composite logger AND its currently attached handlers, so descendant records reaching those handlers are sanitized. Do not install handlers, disable propagation, or change severity/formatter. Document that entry points call this after configuring handlers and repeat when adding handlers; this pure library cannot secure future handlers before they exist. Do not alter root/unrelated loggers on import. Entry-point integration belongs to their later tasks, as settled in T044.
