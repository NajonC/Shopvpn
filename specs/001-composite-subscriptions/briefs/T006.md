## Goal

Add a pytest plugin that keeps every offline test away from the network and from real databases. While pytest runs, it blocks sockets to anything other than loopback, host-name lookups, and SQLite files outside pytest's temporary directory for the run. A test that tries any of these fails, even if the code under test catches the error. The plugin is registered from `tests/conftest.py`, so it is always on.

- `tests/` tree with empty `__init__.py` files in `tests/`, `tests/_harness/`, `tests/unit/`, `tests/integration/` and the other suite folders. No tests yet.
- `tests/conftest.py`: only the docstring `Shared pytest configuration for the composite test suites.`
- `tests/README.md`: suite rules; its "Running Tests" section says `.venv/bin/python -m pytest tests`.
- `.venv/` with Python 3.12.3, pytest 9.1.1, pytest-asyncio 1.4.1 and the bot's runtime packages. No `pytest.ini`, `pyproject.toml`, `setup.cfg` or root `conftest.py`.
- Legacy code opens databases only through `sqlite3.connect(...)` (for example `database.py:474`, `fsm_storage.py:35`); `config.py:38` puts the production database at `<repo>/bot_database.db`.

## Rules

1. "Implement the `--network=deny` pytest plugin in `tests/_harness/network_guard.py` and register it from `tests/conftest.py` … It fails any test that opens a non-loopback socket or selects a database or service path outside a `mktemp` lab root" [tasks.md T006].
2. "Network denial is default for offline fixtures … The future harness must fail if any non-test database/service URL is selected" [quickstart "Proposed post-implementation commands"].
3. "Implementation must provide the denial guard and compatible test runner, with no incidental imports of production config" [quickstart]. The module imports only the standard library and `pytest`, and patches nothing at import time.
4. "All tests MUST use isolated synthetic or sanitized data and MUST NOT use production credentials or call production services" [constitution VI].
5. **Option.** `--network` with `choices=("deny",)` and `default="deny"`. The guard is on with or without the option; any other value is a pytest usage error (exit code 4).
6. **Lifetime.** `pytest_configure` installs the patches; `pytest_unconfigure` restores the saved originals and forgets the lab roots. Installing twice does nothing the second time.
7. **Lab root.** The lab root is pytest's base temporary directory for the run, `tmp_path_factory.getbasetemp()`; every `tmp_path` lives under it. A session-scoped autouse fixture registers its `os.path.realpath`. Until it runs (imports and collection), no file is inside a lab root. A path is inside when `os.path.commonpath([root, os.path.realpath(path)]) == root` for a registered root; a `ValueError` from `commonpath` means outside.
8. **Loopback host.** True for `localhost` (any case), and for an IP literal (after dropping any `%scope` suffix) that `ipaddress.ip_address` reports `is_loopback`, or whose `ipv4_mapped` address is loopback. Everything else is not loopback, including `""` and `0.0.0.0`. A `bytes` host is decoded as ASCII first.
9. **Sockets.** Patch `socket.socket.connect`, `socket.socket.connect_ex`, `socket.socket.bind` and `socket.socket.sendto` (its address is the last positional argument). Check the address by `self.family`, then call the original:
   - `AF_INET`/`AF_INET6`: host is `address[0]`, port `address[1]`; deny unless the host is loopback.
   - `AF_UNIX`: path is `os.fsdecode(address)`; deny if it is empty, starts with `"\0"` (abstract) or is not inside the lab root.
   - any other family: deny.
10. **Name lookups.** Patch `socket.getaddrinfo` (host is the first positional argument or keyword `host`), `socket.gethostbyname` and `socket.gethostbyname_ex`. Allow a host that is `None`, `""`, `localhost` (any case) or any IP literal, since resolving those sends nothing. Deny every other name.
11. **SQLite.** Patch `sqlite3.connect`. `database` is the first positional argument or keyword `database`; `uri` is keyword `uri`, or positional index 7 (counting `database` as 0), default `False`. `bytes` are decoded with `os.fsdecode`, path-like with `os.fspath`.
    - `":memory:"` and `""` are allowed.
    - If `uri` is true and the string starts with `file:`: drop `file:`; cut the rest at the first `#`, then split at the first `?` into path and query. If the path starts with `//`, drop `//` and the authority up to the next `/`; an authority other than `""` or `localhost` is denied. Percent-decode the path with `urllib.parse.unquote`. Allowed if the path is `:memory:` or the query's `mode` (via `urllib.parse.parse_qs`) is `memory`; otherwise check the path as below.
    - Any other value: allowed only if its realpath is inside the lab root. A relative path resolves against the current directory.
    - The check happens before the original is called, so a denied file is never created.
12. **Deny.** Every denial records the message and raises `NetworkGuardError(message)`. Messages, exactly (`host`, `port` and `family` as given; `<path>` is the realpath):
    - `network guard: connect to <host>:<port> is not loopback` (also for `connect_ex`); `bind to …`; `send to …`
    - `network guard: <action> on socket family <family name> is not allowed` (`<action>` is `connect`, `bind` or `send`)
    - `network guard: unix socket <path> is outside the lab root` (`<abstract>` instead of a path for empty or abstract addresses)
    - `network guard: name lookup of <host> is not allowed`
    - `network guard: database <path> is outside the lab root` (for a denied URI authority, `<path>` is the URI text after `file:` without its query)
13. **Failing the test.** Wrap `pytest_runtest_setup`, `pytest_runtest_call` and `pytest_runtest_teardown` as shown under Interfaces. A denial recorded during a phase fails that phase with `pytest.fail("\n".join(messages), pytrace=False)`, even if the code swallowed the `NetworkGuardError`.
14. **Outside a test.** A denial recorded while no phase runs (imports, collection) is kept. `pytest_terminal_summary` writes a `network guard` section (`terminalreporter.section("network guard")`) with one `write_line` per message, and `pytest_sessionfinish` sets `session.exitstatus = pytest.ExitCode.TESTS_FAILED` when the status is `OK` or `NO_TESTS_COLLECTED`.
15. The module docstring states what the guard covers and its limits: child processes started by a test, C extensions with their own sockets, and `sendmsg` are not guarded.

## Tests

File: `tests/integration/test_network_guard.py`. Each test runs a separate inner pytest session in a subprocess with the `pytester` fixture. Use this helper:

```python
REPO_ROOT = Path(__file__).resolve().parents[2]

def _run(pytester, monkeypatch, source, *args):
    monkeypatch.setenv("PYTHONPATH", str(REPO_ROOT))
    pytester.makeconftest('pytest_plugins = ["tests._harness.network_guard"]\n')
    pytester.makepyfile(test_inner=source)
    return pytester.runpytest_subprocess(*args)
```

Pass `"--network=deny"` in every case except 2 and 3. "Caught" means the inner code wraps the call in `try: … except Exception: pass`. Use `timeout=1` on every inner `create_connection`. Check messages with `result.stdout.fnmatch_lines([...])`.

1. `test_deny_option_accepted`: inner `def test_ok(): pass` → `ret == 0`, `assert_outcomes(passed=1)`.
2. `test_guard_on_without_option`: no args; inner test calls `socket.create_connection(("192.0.2.1", 9), timeout=1)` uncaught → `failed=1`, line `*network guard: connect to 192.0.2.1:9 is not loopback*`.
3. `test_other_network_value_rejected`: args `"--network=allow"` → `ret == pytest.ExitCode.USAGE_ERROR`, `result.stderr.fnmatch_lines(["*invalid choice: 'allow'*"])`.
4. `test_loopback_tcp_allowed`: inner server binds `("127.0.0.1", 0)` and listens; a client connects to `("127.0.0.1", port)`, the server accepts, client sends `b"ok"`, server receives `b"ok"`; a second client connects to `("localhost", port)`; everything is closed → `ret == 0`, `passed=1`.
5. `test_external_connect_fails_even_when_caught`: caught `create_connection(("192.0.2.1", 9), timeout=1)` → `failed=1`, line `*network guard: connect to 192.0.2.1:9 is not loopback*`.
6. `test_external_ipv6_connect_fails`: caught `socket.socket(socket.AF_INET6).connect(("2001:db8::1", 9))` → `failed=1`, line `*network guard: connect to 2001:db8::1:9 is not loopback*`.
7. `test_host_name_lookup_fails`: caught `socket.getaddrinfo("example.invalid", 443)` → `failed=1`, line `*network guard: name lookup of example.invalid is not allowed*`.
8. `test_non_loopback_bind_fails`: caught bind of a TCP socket to `("0.0.0.0", 0)` → `failed=1`, line `*network guard: bind to 0.0.0.0:0 is not loopback*`.
9. `test_udp_send_to_external_fails`: caught `sendto(b"x", ("192.0.2.1", 9))` on a UDP socket → `failed=1`, line `*network guard: send to 192.0.2.1:9 is not loopback*`.
10. `test_sqlite_in_lab_root_allowed`: inner test uses `tmp_path`: `sqlite3.connect(tmp_path / "lab.db")` creates a table, inserts `1`, reads back `(1,)`; `sqlite3.connect(str(tmp_path / "lab2.db"))` also opens → `passed=1`.
11. `test_sqlite_memory_allowed`: inner opens and closes `":memory:"`, `""`, `("file::memory:", uri=True)` and `("file:memdb1?mode=memory&cache=shared", uri=True)` → `passed=1`.
12. `test_sqlite_outside_lab_root_fails`: in one inner test, caught `sqlite3.connect("bot_database.db")` and caught `sqlite3.connect(database="kw.db")` → `failed=1`; lines `*network guard: database */bot_database.db is outside the lab root*` and `*network guard: database */kw.db is outside the lab root*`; neither `pytester.path / "bot_database.db"` nor `pytester.path / "kw.db"` exists afterwards.
13. `test_sqlite_uri_outside_lab_root_fails`: caught `sqlite3.connect("file:" + os.path.abspath("outside.db") + "?mode=rwc", uri=True)` → `failed=1`, line `*network guard: database */outside.db is outside the lab root*`; `pytester.path / "outside.db"` does not exist.
14. `test_unix_socket_paths`: inner `test_inside(tmp_path)` binds an `AF_UNIX` socket to `str(tmp_path / "s")` and passes; inner `test_outside()` caught-binds one to `os.path.abspath("svc.sock")` → `passed=1, failed=1`, line `*network guard: unix socket */svc.sock is outside the lab root*`.
15. `test_violation_in_fixture_fails_setup`: inner fixture makes a caught connect to `("192.0.2.1", 9)` then yields; a test using it passes its body → `errors=1`, line `*network guard: connect to 192.0.2.1:9 is not loopback*`.
16. `test_violation_at_import_fails_run`: inner module makes a caught connect to `("192.0.2.1", 9)` at module level, plus `def test_ok(): pass` → `passed=1`, `ret == 1`, lines in order `*= network guard =*` then `*network guard: connect to 192.0.2.1:9 is not loopback*`.
