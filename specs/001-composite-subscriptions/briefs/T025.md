## Tests

File: `tests/characterization/test_database_init.py`. Number each case in a comment (`# Case 1`). Sync tests only. `EXTRA_KEYS = {"_migrated_btn_my_orders_rename", "reseller_tiers_four_level_v2", "reseller_tiers_menu_v2"}`.

1. `test_connect_pragmas`: inside `with db._get_conn() as conn:` `PRAGMA foreign_keys` → `1`, `journal_mode` → `"wal"`, `synchronous` → `1`, `busy_timeout` → `4000` (each `.fetchone()[0]`); `isinstance(conn.execute("SELECT 1 AS a").fetchone(), sqlite3.Row)`; after the block `(tmp_path / "main.db-wal").exists()`.
2. `test_connection_usable_from_another_thread`: open once in the main thread (`SELECT 1`); a `threading.Thread` runs `with db._get_conn() as c: out.append(c.execute("SELECT 2").fetchone()[0])` and stores any exception; after `join`: `out == [2]`, no exception.
3. `test_get_conn_reuses_one_connection`: `db._conn is None` before; two separate `with` blocks yield the same object, and it `is db._conn`.
4. `test_get_conn_commits_on_exit`: `CREATE TABLE t (x INTEGER)` and `INSERT INTO t VALUES (1)` in one block; a `_raw` connection sees `SELECT COUNT(*) FROM t` == `1` while `db` is still open.
5. `test_get_conn_rolls_back_and_reraises`: table `t` created in a first block; `kept = db._conn`; `with pytest.raises(RuntimeError, match="boom"):` a block inserts `(2)` then raises `RuntimeError("boom")`; then `_raw` count of `x = 2` == `0` and `db._conn is kept`.
