**Schema design (Claude's; T036 and T037 build exactly this):**
- Every id is TEXT.
- The plan kind is repeated on each version, under a composite foreign key `(plan_id, kind)` → `composite_plans (plan_id, kind)`, so a version's CHECK can use its kind.
- A subscription's current descriptor per logical node is a row in `composite_subscription_nodes`, keyed by `(subscription_id, logical_node_key)`.
- A `descriptor` is one TEXT value holding the connection values read from the panel. `protocol`, `transport` and `security` are separate columns.
- `restart_xray_on_client_disable` is `'off'`, `'on'` or `'unreadable'`, or NULL until the first check. Its check time is set exactly when the value is.
- `token_digest` is a 32-byte BLOB.
- The five restriction flags are INTEGER 0/1, NOT NULL, DEFAULT 0. `recovery_hold_case` is a nullable case reference, NULL by default.

Helpers, also in the new section:
- `_insert(conn, table, **changes)`: `row = {**BASE_ROWS[table], **changes}`, then one `INSERT INTO <table> (<row keys>) VALUES (?, …)` with `row`'s values in order.
- `_chain(conn, until=None)`: `_insert(conn, t)` for each table `t` of `BASE_ROWS` in order, stopping before `until` (which must be a key of `BASE_ROWS`); `None` inserts all twelve.
- `_one(conn, sql, *args)`: `conn.execute(sql, args).fetchone()`.
- Fixture `main_db(tmp_path)`: `install = _build(tmp_path, "current")`; `migrations.migrate(install.paths(_fresh_dir(tmp_path, "pre-1")), RELEASE)`; `conn = sqlite3.connect(install.main)`; `conn.execute("PRAGMA foreign_keys = ON")`; yield `conn`, close it afterwards.

Expect each refusal with `pytest.raises(sqlite3.IntegrityError, match=…)`:
- **CHECK**: match `"CHECK constraint failed"`.
- **NN `t.c`**: match `re.escape("NOT NULL constraint failed: t.c")`.
- **UQ `t.a, t.b`**: match `re.escape("UNIQUE constraint failed: t.a, t.b")`.
- **FK**: match `"FOREIGN KEY constraint failed"`.
- **TRG**: an `IntegrityError` with any message. Then read the row back and check it is unchanged, or still present after a refused delete.

"Accepted" means the statement runs without error. Every extra row gets its own primary key. Extra panel rows also get their own `authority_fingerprint`, extra tokens their own `token_digest` (`_digest(n)` with a new `n`) and `token_generation`, and extra generations their own `generation`. That way only the value under test can cause a refusal.
