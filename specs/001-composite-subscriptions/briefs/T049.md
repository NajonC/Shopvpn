## Interfaces

- `create_composite_router(*, main_installation_id, main_owner_web_admin_id, public_origin) -> APIRouter` has prefix `/api/composite` and zero endpoints. Every endpoint subsequently added to it inherits a single gate or equivalent dependency stack.
- Reject case-insensitive Bearer Authorization with HTTP403 **before** calling `get_current_admin`, even with valid owner cookie. No mobile telemetry or DB write. Then authenticate cookie through real `get_current_admin`; require both established owner/main guards and `service.web_principal` with trusted mapping. Missing/invalid/expired/inactive cookie returns HTTP401; role/tenant/unmapped owner failures HTTP403. Never echo credentials/private values.
- Save the resulting Principal in `request.state.composite_principal` for future handlers; do not parse identity from body/query/headers.
- Unsafe methods (everything except GET/HEAD/OPTIONS) require BOTH Origin exactly equal to trusted `public_origin` and X-Composite-CSRF equal to lowercase HMAC-SHA256 hex under ADMIN_PANEL_SECRET over `b"composite-csrf-v1\0" + session_cookie.encode()`. Constant-time comparison; malformed/non-ASCII CSRF returns sanitized HTTP403. GET requires auth, not Origin/CSRF. No Referer fallback, Host/forwarded reflection, prefix/suffix matching, or session-independent token.
- `create_configured_composite_router() -> APIRouter`: read environment `COMPOSITE_MAIN_INSTALLATION_ID`, `COMPOSITE_MAIN_OWNER_WEB_ADMIN_ID`, `COMPOSITE_PUBLIC_ORIGIN`. Installation is a nonblank string; owner is explicitly configured positive integer web DB id, never OWNER_ID or inferred first row. Parse env owner without startup exceptions; absent/invalid stays unconfigured. Public origin must be a canonical http/https origin with host, optional port, no credentials/path/query/fragment; preserve nondefault port. No request-derived fallback or guessed deployment values.
- Factory also validates trusted argument types (reject bool/string owner IDs) and invalid origin/installation. An authenticated otherwise authorized request with unusable settings gets sanitized HTTP503, without effects; constructing unconfigured router must not break legacy startup. No secrets in configuration errors. Both helpers document the env names and missing-setting behavior.
- Create module-level `composite_router = create_configured_composite_router()` and call `app.include_router(composite_router)` once in normal app assembly. Do not add test/probe, health, CSRF issuance, business or catch-all endpoints. Later code must register its endpoints before inclusion (FastAPI copies routes).
- HTTP404/422/409 and accepted replay202/200 stay the contract for later business handlers; do not invent placeholder operations/error routes to demonstrate them.
