## Goal

Implement `composite/migrations.py`: the runner that upgrades one installation (the main SQLite file plus every reseller file its `reseller_bots` registry names) to the composite schema. It refuses bad input before touching anything, copies the whole set into an empty pre-upgrade directory, then migrates main and each reseller file in its own explicit transaction. Schema version 1 only adds a `service_kind` discriminator (and, on main, an optional unique `composite_ref`) to three legacy tables; later tasks add the composite tables. The tests already exist and fail only because the module is still empty; make all 55 pass.

## Interfaces

The contract is the test module's docstring, lines 20–70; follow it exactly. How to build it (these settle every point it leaves open):

1. **Constants.** `SCHEMA_VERSION = 1`. `KIND_TABLES = ("products", "test_config_plans", "orders")`. `_STEPS = {1: (_main_v1, _reseller_v1)}`: version → (main step, reseller step), each a function taking the open connection. Keys must be exactly `1..SCHEMA_VERSION`.
2. **Types**, all `@dataclass(frozen=True)`: `AuthorizedPaths(main, tenants, fsm, pre_upgrade_dir, base_dir)` (no validation in the class); `SchemaInfo(version: int, supported: bool)`; `MemberOutcome(path: str, role: str, tenant_id: int | None, from_version: int, to_version: int, status: str)`; `MigrationReport(outcomes: tuple[MemberOutcome, ...])`.
3. **Errors.** `class MigrationError(Exception)`; `RegistryError(MigrationError)`; `UnsupportedSchema(MigrationError)` with `__init__(self, path: str, version: int)` keeping both, message `f"{path} has composite schema version {version}; this release supports up to {SCHEMA_VERSION}"`; `MigrationFailed(MigrationError)` with `__init__(self, report: MigrationReport)` keeping `.report`, message `"migration stopped before every member was migrated; issuance stays disabled"`.
4. **Reading a version** (`_read_version(conn)`): `SELECT 1 FROM sqlite_master WHERE type = 'table' AND name = 'composite_schema_versions'`; no row gives `0`, otherwise `SELECT COALESCE(MAX(version), 0) FROM composite_schema_versions` as an `int`.
5. **`inspect_schema(path)`.** Open read-only: `sqlite3.connect("file:" + urllib.parse.quote(os.path.realpath(path)) + "?mode=ro", uri=True)`. This never creates a missing file (it raises `sqlite3.OperationalError`). Return `SchemaInfo(v, v <= SCHEMA_VERSION)`; close the connection in `finally`. Use this same read-only open wherever this brief says "open read-only".
6. **`issuance_enabled(main_path)`** returns `False`. Nothing can enable composite issuance yet: its switch belongs to the processing-control record a later schema task adds. Say that in its docstring; open no file.
7. **`migrate(paths, expected_release, *, crash=None)`, part A: refusals.** Nothing is created, copied or written until all of these pass, in this order:
   1. `expected_release` must be a non-empty `str`, else `ValueError`.
   2. `pre = os.path.realpath(paths.pre_upgrade_dir)` must be an existing directory with `os.listdir(pre) == []`, else `MigrationError`. Never create it.
   3. `main = os.path.realpath(paths.main)` must be a regular file (`os.path.isfile`), else `MigrationError`.
   4. Open main read-only and read `SELECT id, db_path FROM reseller_bots ORDER BY id`. No such table → `RegistryError`. Each row's `db_path` (not a `str` → `RegistryError`) is used as is when `os.path.isabs`, else `os.path.join(os.fspath(paths.base_dir), db_path)`, then `os.path.realpath`. Let `authorized = {os.path.realpath(t) for t in paths.tenants}`. `RegistryError` when two rows resolve to the same file, a row resolves to `main`, a row's file is not a regular file, a row's file is not in `authorized`, or a file in `authorized` is named by no row.
   5. FSM files: realpath each; `MigrationError` when one is not a regular file, appears twice, or equals `main` or a reseller file.
   6. For each member in order (main, then reseller files by ascending registry id) call `inspect_schema`; the first with `supported` false raises `UnsupportedSchema(realpath, version)`. Keep each `version` as that member's `from_version`.
8. **Part B: the pre-upgrade copy.** Copy every member, then every FSM file, into `pre` with SQLite's online backup: open the source read-only, `dst = sqlite3.connect(os.path.join(pre, name))`, `src.backup(dst)`, close both in `finally`. Names: `main-<basename>`, `reseller-<id>-<basename>`, `fsm-<n>-<basename>` with `n` the 1-based position in `paths.fsm` and `<basename>` that of the realpath. Never change or delete a copy afterwards. An `Exception` here raises `MigrationError(f"pre-upgrade copy of {path} failed")` from it; nothing is migrated.
9. **Part C: one member** (in the same order as A.6). If `from_version == SCHEMA_VERSION`: status `"unchanged"`, open no connection, reach no crash point. Otherwise:
   1. `conn = sqlite3.connect(path, isolation_level=None, timeout=BUSY_TIMEOUT_S)`; `PRAGMA foreign_keys = ON`; `PRAGMA synchronous = FULL`; `BEGIN IMMEDIATE`.
   2. Re-read the version; if it differs from `from_version`, raise `MigrationError(f"composite schema version of {path} changed during the run")`.
   3. `CREATE TABLE IF NOT EXISTS composite_schema_versions (version INTEGER PRIMARY KEY, release TEXT NOT NULL, applied_at INTEGER NOT NULL)`.
   4. For each `v` in `from_version + 1 … SCHEMA_VERSION`: run that version's main or reseller step, then `INSERT INTO composite_schema_versions (version, release, applied_at) VALUES (?, ?, ?)` with `expected_release` and `time.time_ns() // 1_000_000`.
   5. `crash("before commit")` if `crash` is not `None`; `conn.execute("COMMIT")` (never `conn.commit()`); status `"migrated"`, `to_version = SCHEMA_VERSION`; `crash("after commit")` if set.
   6. Close the connection in `finally`, before anything propagates, so a failed run never leaves a lock behind.

   Every statement goes through `conn.execute`, one at a time: no `executescript`, no `executemany` of DDL, no `Database` object.
10. **The two steps of version 1.** For each table `t` in `KIND_TABLES`:
    - `_main_v1`: `ALTER TABLE {t} ADD COLUMN service_kind TEXT NOT NULL DEFAULT 'legacy' CHECK (service_kind IN ('legacy', 'composite'))`; `ALTER TABLE {t} ADD COLUMN composite_ref TEXT`; `CREATE UNIQUE INDEX idx_{t}_composite_ref ON {t} (composite_ref)`. The index must not be partial: SQLite already lets many rows hold `NULL`, and later code looks rows up by this key through `Repository.query_effect`, which accepts only non-partial unique indexes.
    - `_reseller_v1`: `ALTER TABLE {t} ADD COLUMN service_kind TEXT NOT NULL DEFAULT 'legacy' CHECK (service_kind = 'legacy')`. Nothing else.

    Don't skip a column that already exists: a version-0 file that already has one is inconsistent, and the failure must be visible.
11. **Failures inside part C.** Roll back means: if `conn` exists and `conn.in_transaction`, `conn.execute("ROLLBACK")`, ignoring errors from it.
    - An `Exception` before `COMMIT` was executed (open, pragmas, `BEGIN`, re-read, DDL, insert, or `crash("before commit")`): roll back, close, outcome `"failed"` (`to_version = from_version`).
    - An `Exception` from `COMMIT`: close, then the outcome is `"migrated"` if `inspect_schema(path).version == SCHEMA_VERSION`, else `"failed"`; `"failed"` too if that check raises. Never execute `COMMIT` or the steps again.
    - An `Exception` from `crash("after commit")`: the commit stands, outcome `"migrated"`.

    In all three: every later member gets `"not_attempted"` (`to_version = from_version`), and `raise MigrationFailed(MigrationReport(...)) from exc` with the outcomes of every member in order.
    - A `BaseException` that isn't an `Exception` (such as `SimulatedCrash`): roll back, close, then a bare `raise` so the same object propagates. No report.
12. **Result.** `MigrationReport(tuple(outcomes))`, main first, then reseller files by id. `role` is `"main"` or `"reseller"`; `tenant_id` the registry id, `None` for main.
13. **Docstrings.** Module docstring: one paragraph saying the operator must stop every writer of the set before `migrate`, that FSM files are only copied, never changed, and that each member changes in its own explicit transaction. Short docstrings on the public names, in the style of `tests/_harness/crash.py`. English only. No logging and no prints.
