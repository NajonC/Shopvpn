## Goal

Start a controlled, in-memory substitute for one standalone 3x-UI v3.9.0 panel, labelled "substitute, not evidence". This part holds inbounds and clients, answers the API routes the composite code needs through one async `handle()` call, and copies v3.9.0's token scopes, JSON envelope and the client-write rules seen in the lab or read in the v3.9.0 source. Later parts add traffic counters, stalls and an HTTPS front on top of the same object, so keep `handle()` async and the state in one place.

## Rules

1. "Implement a controlled standalone 3x-UI v3.9.0 substitute in `tests/_harness/fake_threexui.py`, modelled on the RX-MAN-001 and GA-MAN-002 observations and labelled 'substitute, not evidence'" [tasks.md T009]. Covered here: "`success: true, obj: null` for missing clients"; "`restartXrayOnClientDisable`, default on, turned back on by a settings reset"; "admin, node-sync and monitor token scopes (403)" [tasks.md T009].
2. **Anything not modelled fails loudly.** A real v3.9.0 route the fake doesn't model, or a real behaviour it doesn't know, raises `FakeNotModelled`. It never returns an invented success. The module docstring says "substitute, not evidence" and lists each behaviour's basis: *lab* (RX-MAN-001/GA-MAN-002 runtime), *source* (v3.9.0 source reading) or *fake choice*.
3. **Envelope** [source, `controller/util.go` `jsonMsgObj`]: HTTP 200 with `{"success": True, "msg": "", "obj": obj}`; failure is HTTP 200 with `{"success": False, "msg": f"Request failed ({error})", "obj": None}`. The texts in brackets below are the `error` part.
4. **Authentication** [source, `controller/api.go`], in this order:
   1. A path not starting with `/panel/api/` → `FakeResponse(404, None)`.
   2. A path matching no route in the two tables below → `404, None`.
   3. `token is None` → `404, None`. A token that is none of the panel's three → `401, None`.
   4. Scope check: `admin` passes everything. `node-sync` passes only (GET `/panel/api/server/status`), (GET `/panel/api/inbounds/list`), (POST `/panel/api/clients/add`), (POST `/panel/api/clients/del/:email`), (POST `/panel/api/clients/update/:email`), (POST `/panel/api/clients/resetTraffic/:email`). `monitor` passes only GET `/panel/api/server/status`. Anything else → `FakeResponse(403, {"success": False, "msg": "this API token is not permitted to access this endpoint"})`.
   5. Then a modelled route runs its handler, and a known unmodelled route raises `FakeNotModelled`.

   Every call is appended to `calls` as `RecordedCall(method, path, scope)`, with `scope=None` for a 404 or 401. No bodies or tokens are recorded.
5. **Modelled routes** (`:email` and `:id` are path parameters; `:id` must be a decimal integer, else `404`):

   | Route | Behaviour |
   | --- | --- |
   | GET `/panel/api/inbounds/list` | `obj`: every inbound as JSON (rule 9), in id order. |
   | GET `/panel/api/inbounds/get/:id` | `obj`: that inbound; missing → error `record not found`. |
   | POST `/panel/api/clients/add` | Rule 7. `obj`: `None`. |
   | POST `/panel/api/clients/update/:email` | Rule 8. `obj`: `None`. |
   | POST `/panel/api/clients/del/:email` | Remove the client from every inbound. Its traffic record is removed too, unless `query["keepTraffic"] == "1"`. Missing → error `client "<email>" not found in any inbound or client record` [source]. Rule 10 restart. `obj`: `None`. |
   | GET `/panel/api/clients/traffic/:email` | `obj`: the traffic record (rule 9); no record → `{"success": True, "msg": "", "obj": None}` [lab]. |
   | POST `/panel/api/setting/all` | `obj`: `{"restartXrayOnClientDisable": bool, "webPort": int, "webBasePath": str}` (fake choice: the real view has many more keys). |
   | GET `/panel/api/server/status` | `obj`: `{"appStats": {"uptime": (true_now_ms - xray_started_ms) // 1000}}` (Xray uptime in seconds [lab]; the real status has more keys). |

6. **Known unmodelled routes** (they authenticate as in rule 4, then raise `FakeNotModelled`). Under `/panel/api/clients`: GET `/list`, `/list/paged`, `/get/:email`, `/get/tgId/:tgId`, `/subLinks/:subId`, `/links/:email`, `/export`; POST `/happLink/:id`, `/renewalPreview`, `/:email/attach`, `/:email/detach`, `/:email/externalLinks`, `/import`, `/delOrphans`, `/resetAllTraffics`, `/delDepleted`, `/bulkAdjust`, `/bulkEnable`, `/bulkDisable`, `/bulkDel`, `/bulkCreate`, `/bulkAttach`, `/bulkDetach`, `/bulkResetTraffic`, `/resetTraffic/:email`, `/updateTraffic/:email`, `/ips/:email`, `/clearIps/:email`, `/hwids/:email`, `/onlines`, `/onlinesByGuid`, `/clientIpsByGuid`, `/activeInbounds`, `/lastOnline`. Under `/panel/api/setting`: POST `/defaultSettings`, `/factoryDefaults`, `/update`, `/validateRegex`, `/updateUser`, `/restartPanel`, `/apiTokens/create`, `/apiTokens/delete/:id`, `/apiTokens/setEnabled/:id`; GET `/getDefaultJsonConfig`, `/apiTokens`. (`resetTraffic` and `updateTraffic` become modelled in part b.)
7. **Add** [source, `ClientCreatePayload`, `ClientService.Create`]. Body `{"inboundIds": [int, …], "client": {…}}`. In order:
   - body missing or not a dict → error `empty payload`;
   - client email empty or missing → `client email is required`;
   - `inboundIds` missing or empty → `at least one inbound is required`; an id that doesn't exist → `inbound <id>: record not found`;
   - a field of the wrong JSON type (rule 11) → `invalid client field: <name>`;
   - `enable` missing → `True`;
   - email already used: if both the existing and the new client have the same non-empty `subId` → raise `FakeNotModelled` (the real result of re-adding the same client is unknown); otherwise → `email already in use: <email>`;
   - a non-empty `subId` used by another email → `subId already in use: <subId>`;
   - the email has a traffic record kept by a `keepTraffic=1` delete → raise `FakeNotModelled` (the real reuse of a kept record is unknown);
   - on a `vless` or `vmess` inbound an empty `id` is replaced by a new `str(uuid.uuid4())` [source, `fillProtocolDefaults`]; on a `trojan` inbound an empty `password` raises `FakeNotModelled`;
   - store one copy per listed inbound, appended to that inbound's client list, with `created_at = updated_at = true_now_ms()`; create the traffic record (rule 9) with `inboundId` = the first listed inbound, `up = down = 0`.
8. **Update** [source, `ClientService.Update`; lab]. Body is the flat client. In order:
   - `query` contains `inboundIds` → raise `FakeNotModelled`;
   - no client with the path email → error `record not found` [lab];
   - wrong field type → `invalid client field: <name>`;
   - body email empty or missing → `client email is required`; a new email already used by another client → `email already in use: <email>`;
   - absolute update: an absent or empty `id`, `password` or `subId`, and `created_at`, keep their stored values [source]; an absent `enable` becomes `False` [source]; every other absent field becomes its zero value (fake choice: the real merge of other fields is unverified, and the strict choice makes composite code send complete records);
   - replace the client in every inbound it is attached to; copy `enable`, the email, `expiryTime`, `totalGB` (as `total`) and `reset` into its traffic record; set `updated_at`. Rule 10 restart.
9. **JSON views.** Client JSON: every rule-11 field, plus `created_at`, `updated_at`; `id`, `password` and `flow` are left out when empty (Go `omitempty`). Traffic record: `{"id": n, "inboundId": int, "enable": bool, "email": str, "up": int, "down": int, "expiryTime": int, "total": int, "reset": int, "lastOnline": 0}`, `id` numbered 1, 2, … per panel; `expiryTime` and `reset` copied from the client, `total` from its `totalGB`. Inbound JSON from the fixture `Inbound` (field-name mapping is the Xray stream-settings schema; *fake choice*, not checked against v3.9.0 output):
   - `{"id", "up": 0, "down": 0, "total": 0, "remark": f"inbound-{id}", "enable": True, "expiryTime": 0, "listen": "", "port": listen_port, "protocol", "tag": f"inbound-{listen_port}", "sniffing": {"enabled": False}, "settings", "streamSettings", "clientStats"}`;
   - `settings`: `{"clients": [client JSON, …]}` plus `"decryption": "none"` for vless;
   - `clientStats`: traffic records of the inbound's clients, in client order;
   - `streamSettings`: `{"network": transport, "security": security, "externalProxy": [{"forceTls": "same", "dest": host, "port": port, "remark": ""}, …]}` plus, by kind: reality `"realitySettings": {"show": False, "xver": 0, "target": f"{sni}:443", "serverNames": [sni], "privateKey": reality_private_key, "shortIds": [reality_short_id], "settings": {"publicKey": reality_public_key, "fingerprint": fingerprint, "serverName": "", "spiderX": "/"}}`; tls `"tlsSettings": {"serverName": sni, "alpn": [], "settings": {"fingerprint": fingerprint}}`; tcp `"tcpSettings": {"header": {"type": tcp_header_type or "none"}}`; ws `"wsSettings": {"path": ws_path, "host": ws_host, "headers": {}}`; grpc `"grpcSettings": {"serviceName": grpc_service_name, "authority": "", "multiMode": grpc_mode == "multi"}`.
10. **Restart record** [source, `client_inbound_apply.go`; lab]. When `restartXrayOnClientDisable` is `True`, an update that turns an enabled client to disabled, or a successful delete, appends `true_now_ms()` to `xray_restarts` and sets `xray_started_ms` to it. When `False`, neither restarts anything. `xray_started_ms` starts at the panel's creation time.
11. **Client fields** (Go JSON binding): strings `id`, `security`, `password`, `flow`, `email`, `subId`, `comment`; integers `limitIp`, `totalGB`, `expiryTime`, `tgId`, `reset`; boolean `enable`. A `bool` given for an integer field, or an `int` for `enable`, is a wrong type. Unknown keys are ignored. Stored defaults: `""`, `0`, `False`.
12. **Settings.** Defaults `restartXrayOnClientDisable = True` [source], `webPort = 2053`, `webBasePath = "/xui/"`. `reset_settings()` restores all three defaults, as `x-ui setting -reset` does [lab].
13. **Copies.** Every value returned (`FakeResponse.body`, `client()`, `inbound_clients()`) is a deep copy; changing it never changes the panel.
14. The module imports only the standard library, `tests._harness.clock` and `tests._harness.fixtures`. No network, no files, no real sleeps.

    path: str
    scope: str | None          # "admin" | "node-sync" | "monitor" | None

    def __init__(self, fixture: CompositeFixture, panel_key: str, clock: FakeClock) -> None: ...

    @property

    @property
    def calls(self) -> list[RecordedCall]: ...       # a copy
    @property
    def xray_restarts(self) -> tuple[int, ...]: ...
    async def handle(self, method: str, path: str, *, token: str | None = None,
                     query: dict[str, str] | None = None, body: object = None) -> FakeResponse: ...
    def seed_client(self, inbound_ids: list[int], client: dict) -> None: ...
        # rule 7 without auth, calls or restarts; a rule-7 error raises ValueError(error text)

        # one client per credential whose node is on this panel, on that node's inbound:

        # "security": inbound.vmess_cipher, "email", "enable"}; trojan {"password": secret, "email", "enable"}
    def client(self, email: str) -> dict | None: ...           # stored client JSON, or None
    def inbound_clients(self, inbound_id: int) -> list[dict]: ...
    def setting(self, name: str) -> object: ...
    def set_setting(self, name: str, value: object) -> None: ...  # only the three rule-12 keys; else KeyError
    def reset_settings(self) -> None: ...
