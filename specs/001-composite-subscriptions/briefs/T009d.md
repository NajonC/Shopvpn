## Goal

Put a real HTTPS server on `127.0.0.1` in front of the in-memory `FakeThreeXUIPanel`, so later tests can drive the real composite HTTP client (aiohttp, verified TLS, bearer token, a fresh connection per call) against it. The front logs every connection with its open and close times and the requests it carried, and it can hold requests in transit, then deliver or drop them, to reproduce the lab's late-execution cases at the transport level.

## Rules

1. Covered here [tasks.md T009]: "held requests that apply after the client closes, and requests fully delivered whose response is held". Later contract tests need [tasks.md T084]: "peer verification rejects a wrong certificate identity" and "each call uses a fresh connection that is explicitly closed (the socket is observed closed and never reused from a pool), and its close time is recorded as the quarantine origin".
2. Lab facts to copy [research.md RX-MAN-001, V-RX-01(b), (d), (e)]: "b1-rec and b1-half (request not fully delivered): the panel dropped the incomplete request at 5.3 s, and it never executed. split-drop never executed. split-deliver executed when its held bytes arrived after the client closed … b2-late (whole request delivered, response held) executed 3.5 s after the client closed. TLS 1.3 throughout". "d-c4: a create that timed out landed 15 s after dispatch, after a read-back had returned "not found"." "Panel API down about 14 s". And [contracts/provider.md]: "Any timed-out request or local failure after dispatch stays uncertain", so an API outage must look like a refused connection (nothing sent), not a reset after sending.
3. **Server.** HTTPS on `127.0.0.1`, port chosen by the system at the first `start()`. `base_url` is `f"https://127.0.0.1:{port}{base_path}"` (an IP literal, so clients do no name lookup). Use aiohttp's low-level `aiohttp.web.Server` (subclassed for the connection log, rule 7) served with `loop.create_server(..., ssl=context)`, with `access_log=None` and aiohttp's default `handler_cancellation=False`. TLS context: `ssl.create_default_context(ssl.Purpose.CLIENT_AUTH)`, then `load_cert_chain` from PEM files written with `with open(...)` into a `tempfile.TemporaryDirectory()` that is removed right after loading.
4. **Certificate.** `make_certificate()` builds a new self-signed EC P-256 certificate: subject and issuer CN `fake 3x-ui panel`, random serial, valid from real now − 1 hour to real now + 1 day (real time, because TLS checks it), SHA-256 signature, extensions: BasicConstraints CA=true (critical), KeyUsage digital_signature + key_cert_sign (critical), ExtendedKeyUsage serverAuth, SubjectAlternativeName with the given DNS names and IP addresses, SubjectKeyIdentifier, AuthorityKeyIdentifier from that SKI. `sha256_fingerprint` is the lowercase hex SHA-256 of the DER certificate. `client_context()` returns `ssl.create_default_context(cadata=cert_pem.decode("ascii"))`. A front given no certificate makes its own in `__init__` (no event loop needed).
5. **Request mapping**, in this order, after the whole request has been read (`await request.read()`):
   1. Log the request on its connection (rule 7): method, `request.path` (percent-decoded, base path included, no query), `received_ms`.
   2. Base path: `""` means none. Otherwise a path equal to the base path or starting with base path + `/` has it stripped; any other path is answered `404` with an empty body at once, never held, never sent to the panel.
   3. Token: an `Authorization` header starting with `Bearer ` gives the rest as the token; any other or missing header gives `None`.
   4. Query: the first value of each key, as `dict[str, str]`.
   5. Body: an empty body is `None`. Otherwise the content type must be `application/json` and the bytes must decode as UTF-8 JSON; if not, a `FakeNotModelled` is kept (rule 6) and the answer is `500` with an empty body, without calling the panel.
   6. Hold check (rule 8), then `await panel.handle(method, panel_path, token=…, query=…, body=…)`.
6. **Answers.** `FakeResponse(status, None)` → that status, empty body. A dict body → JSON (`aiohttp.web.json_response(body, status=status)`). `ConnectionRefusedError` from `handle()` → the request becomes `"dropped"` and the front aborts its connection without an answer. Any other exception from `handle()`, and the rule 5.5 `FakeNotModelled`, is kept and answered `500` with an empty body; `close()` raises the first kept exception after its cleanup.
7. **Connection log.** A record per TLS connection, created by the `web.Server` subclass's `connection_made(handler, transport)` (aiohttp calls it after the TLS handshake, so a failed handshake leaves no record) and closed by its `connection_lost(handler, exc)`; `request.protocol` is that `handler`. `index` counts 0, 1, 2… in accept order; `opened_ms` and `closed_ms` are the panel's true time when the front sees each event; `requests` keeps the requests read on it, in order. Request `state` is exactly one of `"in transit"`, `"at panel"`, `"answered"`, `"answer dropped"`, `"dropped"`. When an answer is ready, `status` is set and the state becomes `"answered"` if the connection is still open in the log and its transport is not closing, otherwise `"answer dropped"`. `connections` returns frozen snapshots. The front stores no token, header, query or body.
8. **Transit hold.** `hold_requests(match=None)` starts a hold. While it lasts, each request inside the base path for which `match(method, panel_path)` is true (every request when `match` is `None`) is parked once fully read: state `"in transit"`, no panel call, no answer, counted by `held_requests`. Fake choice: the front holds a fully read request, while in the lab the missing bytes were held in the network; the client cannot tell the difference. The hold ends with:
   - `deliver_requests()`: each parked request, in arrival order, is handed to `panel.handle()` before `deliver_requests()` returns (start the call with `asyncio.Task(coro, loop=loop, eager_start=True)`), so a write that needs no waiting has applied when it returns. State `"at panel"`; then its answer follows rules 6–7, whether or not the client is still connected (split-deliver gives `"answer dropped"`).
   - `drop_requests()`: each parked request becomes `"dropped"` and never reaches the panel; the front aborts each still-open connection that carried one.
9. **API down** [lab (e); fake choice: instant]. The panel keeps a private list of running fronts (added by `start()`, removed by `close()`); `api_down()` and `api_up()` call a private method on each, after setting `_api_is_down`. No new public panel API. On API down the front stops listening, so new connections are refused (the client sees a failed connect), aborts every open connection, and ends any hold, dropping its parked requests as `drop_requests()` does. On API up, a socket bound with `SO_REUSEADDR` to the same port and listening exists before `api_up()` returns, and the front serves it again. Pending panel writes are untouched (part c).
10. **close()** stops listening, ends any hold (dropping its parked requests), aborts open connections, cancels the front's handler tasks still running (their pending panel writes stay pending, as when a caller gives up), removes the front from the panel, and returns within 1 s of real time; then it raises the first kept exception. A second `close()` does nothing. `async with` calls `start()` and `close()`.
11. **Misuse.** `RuntimeError`: `start()` a second time, after `close()`, or while the panel API is down; `port` or `base_url` before `start()`; `hold_requests()` during a hold; `deliver_requests()` or `drop_requests()` with no hold. `ValueError` in `__init__`: a `base_path` other than `""` that doesn't start with `/` or ends with `/` (so `"/"`, `"xui"` and `"/xui/"` fail).
12. **Time and secrets.** No real sleeps in the front. Real time is used only for the certificate dates and in `wait_connections_closed()`, which polls until every logged connection has closed and raises `TimeoutError` after `timeout_s` real seconds. The front logs nothing; `repr(server)` shows only the port and base path; the private key never appears in any repr.
13. Add part d to the module docstring's basis list: *lab* for the transport cases of rule 2 and TLS; *source* for the bearer-token header; *fake choice* for holding fully read requests, refusal by closing the listener, `404` outside the base path, `500` for not-modelled requests, empty bodies for `None`, JSON-only bodies, the per-front EC certificate, and times read when the front sees an event.
