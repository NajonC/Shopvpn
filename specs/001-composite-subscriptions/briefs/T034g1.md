**Schema design (Claude's; T040 builds exactly this):**
- `composite_processing_control` has no foreign keys, and `migrate` creates it empty: processing control (T055) writes the row from the external control record. Columns: `control_id` (INTEGER PRIMARY KEY; only `1`, so one row per installation); `installation_id` (TEXT, required, never changes); `restore_epoch` and `operation_generation` (INTEGER, required, default 0, ≥ 0); `admission_mode` (required, `open` or `maintenance`); `maintenance_reason` (text, set exactly when the mode is `maintenance`); `mode_changed_at` (required, epoch ms); `worker_incarnation` and `worker_epoch` (the registered worker and the restore epoch it acknowledged; both set or both NULL); `issuance_enabled` (INTEGER, required, default 0, `0` or `1`).
- Insert: the row starts with no worker (`worker_incarnation` and `worker_epoch` NULL) and with issuance off; any mode, epoch and generation are allowed, so a re-created row can take the external record's values. The row is never deleted.
- Update: `installation_id` never changes. `mode_changed_at` moves forward exactly when `admission_mode` changes, and stays put otherwise. `operation_generation` rises by exactly 1 in the update that enters maintenance (`open` → `maintenance`) and never changes otherwise. `restore_epoch` may change only in an update that starts and ends in maintenance, and only upward (it may jump by more than 1). A worker's `worker_epoch` never changes while `worker_incarnation` stays the same; a new non-NULL `worker_incarnation` registers only while the mode is `open`, with `worker_epoch` equal to the current `restore_epoch`. Clearing both worker columns is allowed. `issuance_enabled` changes freely between 0 and 1.
- `migrations.issuance_enabled(main_path)` returns `True` exactly when the main file's composite schema version is at most `SCHEMA_VERSION` and its `composite_processing_control` row has `issuance_enabled = 1`; `False` when the table or row is missing, the switch is 0, or the schema is newer. It opens the file read-only and changes nothing.

def _put11(conn, changes=None, expected="accepted"):
    row = {**CONTROL_ROW, **(changes or {})}
    cols = tuple(row)

def _set11(conn, changes, expected="accepted"):
