## How to check

You may use the network only for the two `pip install` commands below (installing from PyPI). Run from the repository root:

1. `python3 -m venv .venv`
2. `.venv/bin/pip install pytest pytest-asyncio`, then `.venv/bin/pip show pytest pytest-asyncio` to read the installed versions, and write them into `requirements-dev.txt`.
3. `.venv/bin/pip install -r requirements.txt -r requirements-dev.txt` must finish without errors. (Later test tasks import the bot's modules, so the runtime packages go into the same virtualenv.)
4. `.venv/bin/python -m pytest tests -q` must exit with code 5 ("no tests ran") and print no errors.
5. This must print `ignore ok`:
