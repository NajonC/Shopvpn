## Goal

Add a fake clock for tests. It has a UTC wall clock in epoch milliseconds and a separate monotonic clock, both moved only by the test. A test can make the wall clock jump backwards or forwards, or run fast or slow, while the monotonic clock keeps ticking normally. Later worker tests use it to check that a clock regression or large drift puts time decisions on hold without moving clocks already sold to customers.

## What already exists

- `tests/_harness/__init__.py` (empty) and `tests/_harness/network_guard.py` (the pytest plugin that blocks network access; nothing to change there).
- `tests/unit/__init__.py` (empty). No clock code anywhere yet.
- Interpreter: `.venv/bin/python` (Python 3.12, pytest 9.1.1).

## Rules

1. "Implement a controllable clock in `tests/_harness/clock.py`: a UTC epoch-millisecond wall clock and a separate monotonic clock, with injectable regression and large drift" [tasks.md T007].
2. "Absolute times use UTC epoch milliseconds; explicit timezone is presentation only. No calendar rounding" [data-model.md].
3. "Wall-clock UTC stores absolute events; monotonic timers bound waits; clock regression/large drift raises a hold for affected time decisions until trusted time is restored, without moving sold clocks" [plan.md "Worker lifecycle"]. The fake only *injects* regression and drift. It doesn't detect them and has no thresholds; that is the worker's job (a later task).
4. All values are exact `int` milliseconds. Every argument must be an `int` and not a `bool`; anything else raises `TypeError`. No floats anywhere, so results are exact and repeatable.
5. **Three times.** The clock keeps:
   - *true time*: the real UTC time of the test scenario. Only `advance` moves it;
   - *wall time*: what the clock reports as UTC. It follows true time, plus any steps and drift;
   - *monotonic time*: moved only by `advance`, never backwards.
6. **`advance(ms)`** is time passing. `ms` must be `>= 0`, else `ValueError` and nothing changes. True and monotonic time move by `ms`. Wall time moves by `ms` plus drift (rule 8).
7. **`step_wall(delta_ms)`** is a wall-clock jump, as when someone sets the system clock. Wall time moves by `delta_ms`: negative is a regression, positive a forward jump, `0` does nothing. True and monotonic time don't change.
8. **`set_drift_ppm(ppm)`**: from now on, each `advance(ms)` adds `ms * ppm / 1_000_000` extra milliseconds to wall time. The fraction is kept exactly, using an integer accumulator in units of ms·ppm, and only whole milliseconds are added. On each advance: `acc += ms * ppm`; `whole = acc // 1_000_000`; `wall += ms + whole`; `acc -= whole * 1_000_000`. Python's floor division keeps `acc` in `[0, 1_000_000)`, also for negative ppm. `ppm` must be `>= -1_000_000` (at `-1_000_000` the wall clock stands still), else `ValueError` and nothing changes. Setting a new ppm keeps the accumulator.
9. **`resync()`** restores trusted time: wall time = true time, drift = 0, accumulator = 0. Monotonic time doesn't change.
10. The module imports only the standard library. It reads no system clock: no `time.time`, `time.monotonic` or `datetime.now`.

## Interfaces

```python
DEFAULT_WALL_START_MS = 1_767_225_600_000   # 2026-01-01T00:00:00Z
DEFAULT_MONOTONIC_START_MS = 1_000_000

class FakeClock:
    """Test clock: UTC epoch-millisecond wall clock plus a separate monotonic clock."""

    def __init__(self, *, wall_start_ms: int = DEFAULT_WALL_START_MS,
                 monotonic_start_ms: int = DEFAULT_MONOTONIC_START_MS) -> None: ...
        # true time and wall time both start at wall_start_ms; drift 0, accumulator 0
    def now_ms(self) -> int: ...          # wall time, UTC epoch ms
    def monotonic_ms(self) -> int: ...    # monotonic time, ms
    def true_now_ms(self) -> int: ...     # true time, UTC epoch ms
    def drift_ppm(self) -> int: ...       # current drift
    def advance(self, ms: int) -> None: ...
    def step_wall(self, delta_ms: int) -> None: ...
    def set_drift_ppm(self, ppm: int) -> None: ...
    def resync(self) -> None: ...
```

The `__init__` arguments are checked as in rule 4 (`TypeError`). Give each method a one-line docstring.

## Tests

File: `tests/unit/test_clock.py`. `W = DEFAULT_WALL_START_MS`, `M = DEFAULT_MONOTONIC_START_MS`; each test makes its own `FakeClock()` unless it says otherwise.

1. `test_defaults`: `now_ms() == W == 1_767_225_600_000`, `true_now_ms() == W`, `monotonic_ms() == M == 1_000_000`, `drift_ppm() == 0`; all three time readings are of type `int`.
2. `test_custom_start`: `FakeClock(wall_start_ms=5_000, monotonic_start_ms=7)`: `now_ms() == 5_000`, `true_now_ms() == 5_000`, `monotonic_ms() == 7`.
3. `test_advance_moves_all_three`: `advance(1_500)` → `now_ms() == W + 1_500`, `true_now_ms() == W + 1_500`, `monotonic_ms() == M + 1_500`. Then `advance(0)` changes nothing.
4. `test_advance_rejects_negative`: `advance(-1)` raises `ValueError`; all readings are still the defaults.
5. `test_rejects_non_int_arguments`: each of `advance(1.5)`, `advance(True)`, `advance("1")`, `step_wall(1.0)`, `step_wall(False)`, `set_drift_ppm(0.5)`, `FakeClock(wall_start_ms=1.0)`, `FakeClock(monotonic_start_ms=True)` raises `TypeError`.
6. `test_regression`: `step_wall(-60_000)` → `now_ms() == W - 60_000`, `true_now_ms() == W`, `monotonic_ms() == M`. Then `advance(1_000)` → `now_ms() == W - 59_000`, `true_now_ms() == W + 1_000`, `monotonic_ms() == M + 1_000`.
7. `test_forward_jump`: `step_wall(3_600_000)` → `now_ms() == W + 3_600_000`, `true_now_ms() == W`, `monotonic_ms() == M`. `step_wall(0)` changes nothing.
8. `test_fast_drift`: `set_drift_ppm(500_000)`, `advance(1_000)` → `now_ms() == W + 1_500`, `true_now_ms() == W + 1_000`, `monotonic_ms() == M + 1_000`.
9. `test_slow_drift`: `set_drift_ppm(-250_000)`, `advance(4_000)` → `now_ms() == W + 3_000`, `monotonic_ms() == M + 4_000`.
10. `test_drift_fraction_is_exact`: `set_drift_ppm(1)`, `advance(999_999)` → `now_ms() == W + 999_999`; then `advance(1)` → `now_ms() == W + 1_000_001`, `monotonic_ms() == M + 1_000_000`.
11. `test_negative_drift_fraction`: `set_drift_ppm(-1)`, `advance(1)` → `now_ms() == W`; then `advance(999_999)` → `now_ms() == W + 999_999`.
12. `test_frozen_wall_and_drift_limit`: `set_drift_ppm(-1_000_000)`, `advance(5_000)` → `now_ms() == W`, `monotonic_ms() == M + 5_000`. `set_drift_ppm(-1_000_001)` raises `ValueError` and `drift_ppm()` is still `-1_000_000`.
13. `test_drift_back_to_zero`: `set_drift_ppm(500_000)`, `advance(1_000)`, `set_drift_ppm(0)`, `advance(1_000)` → `now_ms() == W + 2_500`, `drift_ppm() == 0`.
14. `test_resync`: `step_wall(-30_000)`, `set_drift_ppm(100_000)`, `advance(10_000)` → `now_ms() == W - 19_000`. Then `resync()` → `now_ms() == W + 10_000 == true_now_ms()`, `drift_ppm() == 0`, `monotonic_ms() == M + 10_000`. Then `advance(1_000)` → `now_ms() == W + 11_000`.
15. `test_resync_clears_accumulator`: `set_drift_ppm(1)`, `advance(999_999)`, `resync()`, `set_drift_ppm(1)`, `advance(1)` → `now_ms() == W + 1_000_000` (the old fraction is gone).
16. `test_clocks_are_independent`: advancing one `FakeClock` leaves a second one at its defaults.
17. `test_reads_no_system_clock`: with `monkeypatch` replacing `time.time`, `time.time_ns`, `time.monotonic` and `time.monotonic_ns` by a function that raises `AssertionError`, create a `FakeClock()`, call every method once, and read every value. No error is raised.
