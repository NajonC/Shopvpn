## Goal

Add two factory functions that build the synthetic test world for composite subscriptions: the six-node acceptance fixture, and the A-only five-choice offer. Each returns plain frozen dataclasses describing tenants, customers, web admins, panels, panel aliases, inbounds, nodes and subscriptions with their credentials. Later tests seed fake panels and databases from them. Secrets are new random values on every call and are never written anywhere.

## What already exists

- `tests/_harness/`: `network_guard.py` (pytest plugin), `clock.py` (`FakeClock`). Nothing to change there.
- `tests/unit/test_fixture_secrets.py`: secret tests written by Claude, already staged. They fail now only because `tests/_harness/fixtures.py` doesn't exist. Don't change this file.
- Legacy reseller stores have their own database file and a `miniapp_tenant_id` setting (`bot_manager.py:441`); `users.telegram_id`, not `users.id`, identifies a customer.
- Interpreter: `.venv/bin/python` (Python 3.12, pytest 9.1.1).

## Rules

1. Follow the spec FR-002 fixture table [tasks.md T008; spec FR-002]:

   | Fixture node | Intended location and protocol | Independent identity | Required remark / result |
   | --- | --- | --- | --- |
   | A-US | A's single REALITY inbound, public 443 | Separate VLESS UUID, illustrative email `ali_sub1_us` | `🇺🇸 US - Reality`; actual US egress |
   | A-DE | Same A inbound | Separate VLESS UUID, illustrative email `ali_sub1_de` | `🇩🇪 DE - Reality`; actual DE egress |
   | A-RU | Same A inbound | Separate VLESS UUID, illustrative email `ali_sub1_ru` | `🇷🇺 RU - Reality`; actual RU egress |
   | B-CDN | B inbound 1, VLESS-WS-CDN | Independent VLESS UUID | `Server B - CDN`; B's configured route |
   | B-gRPC | B inbound 2, Trojan-gRPC | Independent Trojan password | `Server B - gRPC`; B's configured route |
   | C-Direct | C inbound 1, VMess-TCP-TLS | Independent VMess UUID | `Server C - Direct`; direct egress |

2. "Fixture identities are synthetic illustrations, not production naming rules or secrets. Inbound numbers may coincide across panels without identifying the same resource. The fixture has six real nodes … and uses one 50-GiB/30-day subscription. It also needs a second subscription for the same customer, another customer, overlapping tenant/local identities and panel aliases for isolation checks" [spec FR-002].
3. "The initial live A-only offer with five explicitly configured choices/independently routed credentials on A's prepared inbound" [spec FR-002].
4. "Secrets are generated per run and never written to the repository" [tasks.md T008]. Every secret is a new random value on each call, from `secrets` or `uuid.uuid4`. Secret fields use `field(repr=False)`, so printing a fixture never shows them. The module writes no files and makes no network calls.
5. Exact units: one GiB is 1,073,741,824 bytes; 30 days is 2,592,000 seconds [spec FR-003].
6. All hosts end in `.example.invalid`, so they can never resolve.
7. The module imports only the standard library (`dataclasses`, `secrets`, `uuid`).
8. All dataclasses are `@dataclass(frozen=True)`; collections in them are tuples.

## Interfaces

```python
@dataclass(frozen=True)
class Tenant:
    key: str                  # "main" | "reseller"
    tenant_id: str            # "main" | "reseller-7"
    installation_id: str      # str(uuid.uuid4()), new per call; not a secret

@dataclass(frozen=True)
class Customer:
    key: str
    tenant_key: str
    telegram_id: int
    local_user_id: int        # users.id in that tenant's database

@dataclass(frozen=True)
class WebAdmin:
    admin_row_id: int
    username: str
    role: str                 # "owner" | "staff"

@dataclass(frozen=True)
class Panel:
    key: str                  # "A" | "B" | "C"
    physical_panel_id: str    # str(uuid.uuid4()), new per call; not a secret
    base_url: str
    api_token: str = field(repr=False)          # secrets.token_urlsafe(32)

@dataclass(frozen=True)
class PanelAlias:
    installation_id: str      # the owning tenant's installation_id
    tenant_id: str
    local_panel_server_id: int
    panel_key: str

@dataclass(frozen=True)
class ExternalProxy:
    host: str
    port: int

@dataclass(frozen=True)
class Inbound:
    panel_key: str
    inbound_id: int
    protocol: str             # "vless" | "trojan" | "vmess"
    transport: str            # "tcp" | "ws" | "grpc"
    security: str             # "reality" | "tls"
    listen_port: int
    external_proxies: tuple[ExternalProxy, ...]
    sni: str
    fingerprint: str
    flow: str = ""
    ws_host: str = ""
    ws_path: str = ""
    grpc_service_name: str = ""
    grpc_mode: str = ""
    vmess_cipher: str = ""
    tcp_header_type: str = ""
    reality_public_key: str = field(default="", repr=False)   # REALITY only
    reality_private_key: str = field(default="", repr=False)  # REALITY only
    reality_short_id: str = field(default="", repr=False)     # REALITY only

@dataclass(frozen=True)
class Node:
    key: str
    ordinal: int              # 1-based, the export order
    panel_key: str
    inbound_id: int
    remark: str
    egress: str               # outbound tag on that panel

@dataclass(frozen=True)
class Credential:
    node_key: str
    email: str
    secret_kind: str          # "uuid" (VLESS/VMess) | "password" (Trojan)
    secret: str = field(repr=False)

@dataclass(frozen=True)
class Subscription:
    key: str
    customer_key: str
    allowance_bytes: int
    duration_seconds: int
    node_keys: tuple[str, ...]
    credentials: tuple[Credential, ...]          # one per node, in node order
    url_token: str = field(repr=False)          # secrets.token_urlsafe(32)

@dataclass(frozen=True)
class CompositeFixture:
    tenants: tuple[Tenant, ...]
    customers: tuple[Customer, ...]
    web_admins: tuple[WebAdmin, ...]
    main_owner_telegram_id: int
    panels: tuple[Panel, ...]
    aliases: tuple[PanelAlias, ...]
    inbounds: tuple[Inbound, ...]
    nodes: tuple[Node, ...]
    subscriptions: tuple[Subscription, ...]

    # Each lookup returns the matching item or raises KeyError.
    def tenant(self, key: str) -> Tenant: ...
    def customer(self, key: str) -> Customer: ...
    def panel(self, key: str) -> Panel: ...
    def inbound(self, panel_key: str, inbound_id: int) -> Inbound: ...
    def node(self, key: str) -> Node: ...
    def subscription(self, key: str) -> Subscription: ...

GIB = 1_073_741_824
PAID_ALLOWANCE_BYTES = 50 * GIB          # 53_687_091_200
PAID_DURATION_SECONDS = 2_592_000

def six_node_fixture() -> CompositeFixture: ...
def a_only_offer_fixture() -> CompositeFixture: ...
```

Secret formats: VLESS/VMess `str(uuid.uuid4())`; Trojan `secrets.token_urlsafe(18)`; panel token and URL token `secrets.token_urlsafe(32)`; REALITY public and private key each `secrets.token_urlsafe(32)` (32 random bytes, 43 characters; synthetic, not a real key pair); REALITY short ID `secrets.token_hex(4)`.

- Panel base URLs: `https://panel-a.example.invalid:2053/xui`, and `panel-b`, `panel-c` likewise.
- Email pattern: `<customer>_sub<n>_<suffix>`, suffix `us`, `de`, `ru`, `cdn`, `grpc`, `direct`, `nl`, `fi`.

`six_node_fixture()`:
- panels `A`, `B`, `C`.
- aliases (tenant, local id → panel): main 1 → A; main 2 → B; main 3 → C; reseller 1 → B; reseller 9 → A.
- inbounds:
  - A 1: vless, tcp, reality, listen 443, proxy `a.example.invalid:443`, sni `a.example.invalid`, fingerprint `chrome`, flow `xtls-rprx-vision`, REALITY keys and short ID generated.
  - B 1: vless, ws, tls, listen 8443, proxy `cdn-b.example.invalid:443`, sni `cdn-b.example.invalid`, fingerprint `chrome`, ws_host `cdn-b.example.invalid`, ws_path `/vless-ws`.
  - B 2: trojan, grpc, tls, listen 2083, proxy `b.example.invalid:2083`, sni `b.example.invalid`, fingerprint `chrome`, grpc_service_name `trojan-grpc`, grpc_mode `gun`.
  - C 1: vmess, tcp, tls, listen 8443, proxy `c.example.invalid:8443`, sni `c.example.invalid`, fingerprint `chrome`, vmess_cipher `auto`, tcp_header_type `none`.
- nodes (ordinal, key, panel, inbound, remark, egress): 1 `A-US` A 1 `🇺🇸 US - Reality` `out-us`; 2 `A-DE` A 1 `🇩🇪 DE - Reality` `out-de`; 3 `A-RU` A 1 `🇷🇺 RU - Reality` `out-ru`; 4 `B-CDN` B 1 `Server B - CDN` `out-b`; 5 `B-gRPC` B 2 `Server B - gRPC` `out-b`; 6 `C-Direct` C 1 `Server C - Direct` `direct`.

`a_only_offer_fixture()`:

- nodes: 1 `A-US`, 2 `A-DE`, 3 `A-RU` as above; 4 `A-NL` A 1 `🇳🇱 NL - Reality` `out-nl`; 5 `A-FI` A 1 `🇫🇮 FI - Reality` `out-fi`.
- one subscription `ali-1` with the five nodes, the same allowance and duration, five `uuid` credentials.
