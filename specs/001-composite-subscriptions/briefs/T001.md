## Goal

Create the empty `composite/` Python package that later tasks fill in. "Composite subscriptions" is a new kind of VPN plan in this Telegram bot: one purchase gives the customer several independent VPN credentials on 3x-UI panels, sharing one data allowance, one expiry date and one subscription URL. This packet only creates the files, each with a docstring saying what the module will hold. No code.

## What already exists

Nothing yet. There is no `composite/` folder. The existing bot is a flat set of modules at the repository root (`database.py`, `handlers_user.py`, …) plus the `panel_providers/` package.

## Rules

1. "Module docstrings only; nothing reads production configuration" [tasks.md T001]. Each file contains exactly one module docstring and nothing else: no imports, no functions, no classes, no constants.
2. Importing any of these modules must have no side effects (no file, database, network or environment access).
3. Docstrings are in English, 1–4 lines each, plain description of the module's job taken from the table under Files. Don't invent features beyond it.

## Files

Create (each with its docstring's content):

| File | What the module will hold |
| --- | --- |
| `composite/__init__.py` | The composite subscriptions package: one purchase bundles several independent 3x-UI credentials under one shared data allowance, one expiry and one subscription URL. |
| `composite/service.py` | The application boundary. Receives an authenticated main-store principal, never trusts client-supplied IDs for authority, and runs one database transaction per command. |
| `composite/repository.py` | Database access for the composite tables. |
| `composite/models.py` | Domain types: plans, subscriptions, child credentials and their states. |
| `composite/migrations.py` | Versioned, additive schema migrations for the composite tables. |
| `composite/finance.py` | Pricing and quotes, the integer wallet ledger, payment attempts, refunds and credits. |
| `composite/accounting.py` | Usage meters, ingestion of traffic observations, and enforcement of the shared allowance and expiry. |
| `composite/lifecycle.py` | Panel registration, prepared bindings, the remote credential lifecycle, the reconciliation sweep and revocation. |
| `composite/exports.py` | Builds the per-node connection entries that make up a subscription. |
| `composite/worker.py` | The background worker that runs the financial, remote-work and meter-collection lanes. |
| `composite/subscription_server.py` | The public, read-only subscription endpoint that serves Base64 subscription content. It never calls a panel. |
| `composite/notifications.py` | Delivery of customer and owner notifications. |
| `composite/operations.py` | Owner operations: processing control (pause/resume), server moves and recovery. |
| `composite/cli.py` | Lab commands for testing; they refuse any path outside a lab root. |
| `composite/secrets.py` | Encryption of panel tokens, child secrets and other stored secrets. |
| `composite/audit.py` | Immutable audit events and sanitized diagnostics. |
| `composite/payment_methods/__init__.py` | Per-payment-method adapters, each added once that method's contract is verified. |

Touch nothing else.

## How to check

```bash
python3 - <<'EOF'
import ast, importlib, pathlib
mods = ["composite", "composite.service", "composite.repository", "composite.models",
        "composite.migrations", "composite.finance", "composite.accounting",
        "composite.lifecycle", "composite.exports", "composite.worker",
        "composite.subscription_server", "composite.notifications",
        "composite.operations", "composite.cli", "composite.secrets",
        "composite.audit", "composite.payment_methods"]
for m in mods:
    p = pathlib.Path(m.replace(".", "/"))
    p = p / "__init__.py" if p.is_dir() else p.with_suffix(".py")
    body = ast.parse(p.read_text(encoding="utf-8")).body
    assert len(body) == 1 and isinstance(body[0], ast.Expr) \
        and isinstance(body[0].value, ast.Constant) \
        and isinstance(body[0].value.value, str), f"{p}: must hold only a docstring"
    importlib.import_module(m)
print("ok", len(mods))
EOF
git status --porcelain
```
