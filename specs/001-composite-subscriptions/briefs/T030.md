Helpers:
- `_sign(secret, payload) -> str`: `body = base64.urlsafe_b64encode(json.dumps(payload, separators=(",", ":")).encode()).rstrip(b"=").decode()`, returns `body + "." + hmac.new(secret.encode(), body.encode(), hashlib.sha256).hexdigest()`.
- `_payload(token) -> dict`: decodes the body part (add `=` padding) with `base64.urlsafe_b64decode` and `json.loads`.
- `_sha(text) -> str`: `hashlib.sha256(text.encode()).hexdigest()`.
- `_refused(call) -> tuple`: runs `call()` inside `pytest.raises(HTTPException)` and returns `(status_code, detail)`.
- `_rows(db, sql, params=())`: as in `test_unsupported_surfaces.py` line 96.
- `_call(web, method, url, cookie=None, bearer=None, headers=None, **kwargs) -> httpx.Response`: adds `Cookie: panel_session=<cookie>` when `cookie` is given and `Authorization: Bearer <bearer>` when `bearer` is given; passes `follow_redirects=False`.
- `_cookie(web, admin_id, tenant="", role="owner", username="x", ttl_seconds=3600)`: `session_cookie(web.secret, admin_id, username, role, tenant, ttl_seconds)`.
- `_attrs(set_cookie) -> list`: `set_cookie.split("; ")[1:]`; `_cookie_value(set_cookie)`: the text between `panel_session=` and the first `;`.
