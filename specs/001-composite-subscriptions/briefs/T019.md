## Tests

File: `tests/contract/test_provider_factory_legacy.py`. Number each case in a comment (`# Case 1`). Parametrize with `ids` so each identifier shows in the test id.

1. `test_registry_has_the_eleven_identifiers_in_order`: `list(panel_providers.PROVIDERS) == IDENTIFIERS` and `{k: c.__name__ for k, c in panel_providers.PROVIDERS.items()} == CLASS_NAMES`.
2. `test_labels_cover_the_same_identifiers`: `panel_providers.PANEL_TYPE_LABELS == LABELS` and `list(panel_providers.PANEL_TYPE_LABELS) == IDENTIFIERS`.
3. `test_get_provider_builds_the_registered_class` (parametrized over `IDENTIFIERS`): `server = {"panel_type": ident}`; `provider = panel_providers.get_provider(server)`; `type(provider) is panel_providers.PROVIDERS[ident]`, `isinstance(provider, base.BasePanelProvider)`, `provider.server is server`, and `type(provider).__mro__[1] is base.BasePanelProvider`.
4. `test_unknown_type_fails_with_panel_error` (parametrized over `"marzban2"`, `""`, `"3XUI"`): `pytest.raises(base.PanelError)`; `type(exc) is base.PanelError` and `str(exc) == UNSUPPORTED_TYPE.format(value)`.
5. `test_missing_panel_type_raises_key_error`: `get_provider({})` raises `KeyError` with `exc.args == ("panel_type",)`; `isinstance(exc, base.PanelError)` is False.
6. `test_result_and_error_types`: `[(f.name, f.type, f.default) for f in dataclasses.fields(P)] == [("username", str, dataclasses.MISSING), ("subscription_url", str, dataclasses.MISSING), ("raw", dict, None)]`; `P("u1", "https://sub.example.invalid/u1").raw is None`; `P("u1", "x") == P("u1", "x")`; `base.PanelError.__bases__ == (Exception,)`; `base.PanelUsernameTakenError.__bases__ == (base.PanelError,)`; the package re-exports are the same objects: `panel_providers.PanelError is base.PanelError`, likewise `PanelUserResult`, `PanelUsernameTakenError`, `BasePanelProvider`.
7. `test_base_class_is_abstract`: `base.BasePanelProvider.__abstractmethods__ == frozenset(ABSTRACT)`; `base.BasePanelProvider({"panel_type": "3xui"})` raises `TypeError`; `params(base.BasePanelProvider.__init__) == [("server", E, E)]`.
8. `test_base_signatures`: for each `name, (expected_params, ret)` in `BASE_SIGNATURES`: `method = getattr(base.BasePanelProvider, name)`; `params(method) == expected_params`; `inspect.signature(method).return_annotation is ret`; `inspect.iscoroutinefunction(method)`.
9. `test_every_provider_keeps_the_base_signatures` (parametrized over `IDENTIFIERS`): for each name in `BASE_SIGNATURES`, on `cls = panel_providers.PROVIDERS[ident]`: `params(getattr(cls, name)) == BASE_SIGNATURES[name][0]`, coroutine function, and return annotation equal to `BASE_SIGNATURES[name][1]` except `rename_user` when `ident in {"3xui", "hiddify", "alireza"}`, whose return annotation `is None`.
10. `test_optional_capability_overrides`: `{k for k, c in panel_providers.PROVIDERS.items() if "set_enabled" in c.__dict__} == SET_ENABLED_OVERRIDES` and the same with `"rename_user"` `== RENAME_OVERRIDES`.
11. `test_default_set_enabled_fails_explicitly` (parametrized over the identifiers not in `SET_ENABLED_OVERRIDES`: `wgdashboard`, `mikrotik`, `ibsng`): `asyncio.run(panel_providers.get_provider({"panel_type": ident}).set_enabled("u1", False))` raises `base.PanelError` with `str(exc) == NO_SET_ENABLED`.
12. `test_default_rename_user_fails_explicitly` (parametrized over `pasarguard`, `marzban`, `rebecca`, `sui`, `wgdashboard`, `mikrotik`, `ibsng`): `rename_user("u1", "u2")` the same way raises `base.PanelError` with `str(exc) == NO_RENAME`.
13. `test_volume_units_are_binary_gigabytes` (units): `gb_to_bytes(1) == 1073741824`, `gb_to_bytes(0.5) == 536870912`, `gb_to_bytes("2") == 2147483648`, `gb_to_bytes(0) == 0`, `gb_to_bytes(1e-10) == 0` (truncated, not rounded).
14. `test_new_limit_rule` (parametrized; `preserve_remaining`): `new_limit_bytes(current, used, add_gb, reset_usage, preserve_remaining) == expected`, with ids:
    - `additive`: `(10 * GIB, 3 * GIB, 20, False, False)` → `30 * GIB`
    - `preserve_ignored_without_reset`: `(10 * GIB, 3 * GIB, 20, False, True)` → `30 * GIB`
    - `full_replacement`: `(10 * GIB, 3 * GIB, 20, True, False)` → `20 * GIB`
    - `full_carryover`: `(10 * GIB, 3 * GIB, 20, True, True)` → `27 * GIB`
    - `carryover_overused_clamps_to_zero`: `(10 * GIB, 12 * GIB, 20, True, True)` → `20 * GIB`
    - `replacement_without_volume_keeps_limit`: `(10 * GIB, 3 * GIB, 0, True, False)` → `10 * GIB`
    - `carryover_without_volume_shrinks_to_remaining`: `(10 * GIB, 3 * GIB, 0, True, True)` → `7 * GIB`
    - `none_values_count_as_zero`: `(None, None, 0.5, False, False)` → `536870912`
    - `all_zero`: `(0, 0, 0, False, False)` → `0`
    - `none_add_and_used`: `(10 * GIB, None, None, True, True)` → `10 * GIB`
