## What already exists

All HTTP goes through `async def _request(method, url, headers=None, json_body=None, timeout=25)` (30–43), which returns `(status, data)` with `data` always a dict. Constants `TETRA98_BASE = "https://tetra98.com"`, `CUBEPAY_BASE = "https://cubevps.ir/smspay/api"`, `NOWPAYMENTS_BASE = "https://api.nowpayments.io/v1"`, `PAID = "paid"`, `PENDING = "pending"`, `FAILED = "failed"`; `class GatewayError(Exception)`.
  - `tetra98_create(api_key, amount_toman, callback_url, description, order_number)` (117–132): POST `/api/create_order`, no headers, body `{"ApiKey", "Hash_id": order_number, "Amount": int(amount_toman) * 10, "Description": str(description)[:200], "CallbackURL"}`. `str(status) == "100"` and `Authority` → `{"remote_id": str(authority), "payment_url": payment_url_web or f"{TETRA98_BASE}/payment/{authority}", "meta": {"bot_url": payment_url_bot or ""}}`; else `GatewayError(f"تترا۹۸: {message or 'خطا در ساخت سفارش'} (HTTP {status}).")`.
  - `tetra98_verify(api_key, authority)` (135–144): POST `/api/verify`, body `{"ApiKey", "authority"}`. HTTP 200 and `str(status) == "100"` → paid; HTTP ≥ 500 → `GatewayError`; anything else → pending. It never returns failed and never reads an amount or order.
  - `cubepay_payable_toman(amount_toman, fee)` (147–153): fee ≤ 0 → the amount; fee ≤ 100 → percentage, rounded up; fee > 100 → `base + int(round(fee))` Toman.

  - `cubepay_verify(token, authority, order_number, expected_rial)` (182–205): for HTTP 200/409, a present `order_id` must equal the order and a present, parseable `amount` must be ≥ `expected_rial` (both raise `GatewayError`); then 409 or `success` → paid. 402 → pending; 404/410 → failed; ≥ 500 → `GatewayError`; else pending.
  - `nowpayments_create_invoice(api_key, price_usd, order_number, description, ipn_url)` (208–223), `nowpayments_payment_status(api_key, payment_id)` (226–233: GET, non-200 → `GatewayError`, else the reply dict as is), `nowpayments_classify(payment, remote_invoice_id, order_number, expected_usd)` (236–251), `nowpayments_verify_ipn_signature(secret, body, signature)` (254–259: HMAC-SHA512 hex over `json.dumps(body, sort_keys=True, separators=(",", ":"), ensure_ascii=False)`, compared with `signature.strip().lower()`; empty secret or signature → False).
