## What already exists

- `payment_engine.py` (do not change). Pure functions, no I/O in the parts tested here. Logger: `logging.getLogger("payment_engine")`.
  - `amounts_match(paid_amount, expected_toman, tolerance_percent: float = 1.0) -> bool` (lines 126–143): `paid_amount is None` → True; `paid = float(str(paid_amount).replace(",", "").strip())` and `expected = float(expected_toman)`, a `TypeError`/`ValueError` in either → True; `expected <= 0` → True; `tolerance = max(0.0, tolerance_percent) / 100.0` (outside the try, so `None` raises `TypeError`); returns `paid >= expected * (1.0 - tolerance)`. There is no upper bound and no currency check.
  - `GenericGateway(config)` (218–223): `self.config = config or {}`.
  - `GenericGateway.check_webhook_auth(headers, query, raw_body) -> bool` (287–317): `auth_cfg = config.get("webhook_auth") or {}`; `mode = auth_cfg.get("mode") or "none"`; `"none"` → True before anything else is read. Otherwise `secret = credentials.get(auth_cfg.get("secret_field") or "") or ""`; header names are lowercased. `"header_secret"`: header `header_name` (case-insensitive) must equal the secret and the secret must be non-empty. `"query_secret"`: query key `query_param` (case-sensitive) likewise. `"hmac_sha256"` or `"hmac"`: header `header_name` holds the signature; empty secret or signature → False; `digestmod = getattr(hashlib, hmac_algo.lower() or "sha256", hashlib.sha256)`; expected `hmac.new(secret.encode("utf-8"), raw_body or b"", digestmod).hexdigest()` compared with the signature after `.strip().lower()`. Any other mode → `logger.warning("حالت webhook_auth ناشناخته: %s", mode)` and False.
  - `GenericGateway.parse_webhook(body, query) -> dict` (319–344): returns `{"txn_id", "status_value", "success", "amount"}`; `amount` is None unless `webhook_mapping["amount_path"]` is set; `success` is None when `success_values` is empty.

- House style: `tests/characterization/test_sub_info_export.py` lines 1–30 (module docstring, imports, constants block). One statement per line (no `;`). Interpreter `.venv/bin/python`. Full suite today: 602 passed.

## Tests

File: `tests/characterization/test_payment_methods_legacy.py`. `amounts_match(p, e)` below means `amounts_match(p, e)` with the default tolerance unless a third argument is shown. Each case asserts every listed value (a loop or `pytest.mark.parametrize` is fine).

1. `test_amounts_match_accepts_missing_paid_amount`: `amounts_match(None, EXPECTED)` is True; `amounts_match(None, EXPECTED, 0)` is True.
2. `test_amounts_match_accepts_unparseable_paid_amount`: for each of `""`, `"abc"`, `"100 تومان"`, `"12.5.3"`, `[]`, `{}`, `True`, `False`, `object()`: `amounts_match(p, EXPECTED)` is True.
3. `test_amounts_match_accepts_any_paid_amount_when_expected_is_unusable`: for each expected of `None`, `"abc"`, `0`, `-5`, `"0"`: `amounts_match(0, e)` is True.
4. `test_amounts_match_default_one_percent_floor`: with `EXPECTED`: `99_000` → True, `99_000.0` → True, `"99000"` → True, `98_999.99` → False, `98_999` → False, `0` → False, `-1` → False.
5. `test_amounts_match_has_no_upper_bound`: `100_001`, `1_000_000`, `10**12` and `"inf"` → True each.
6. `test_amounts_match_paid_string_parsing`: `" 100,000 "` → True; `"9,9,0,0,0"` → True (every comma is removed); `"98,999"` → False; `"1e5"` → True; `"۱۰۰۰۰۰"` (Persian digits) → True; `"nan"` → False.
7. `test_amounts_match_tolerance_argument`: `amounts_match(99_999, EXPECTED, 0)` False; `amounts_match(100_000, EXPECTED, 0)` True; `amounts_match(99_999, EXPECTED, -5)` False (negative becomes 0); `amounts_match(95_000, EXPECTED, 5)` True; `amounts_match(94_999, EXPECTED, 5)` False; `amounts_match(0, EXPECTED, 100)` True; `amounts_match(-1, EXPECTED, 150)` True; `amounts_match(1, 100, None)` raises `TypeError`.
8. `test_amounts_match_has_no_currency_or_unit_check`: `amounts_match(1_000_000, EXPECTED)` True (a Rial figure for a Toman invoice); `amounts_match(10, EXPECTED)` False; `amounts_match(1, "100,000")` True (commas are stripped from the paid amount only, so the expected amount is unparseable).
9. `test_check_webhook_auth_defaults_to_mode_none`: for each config of `None`, `{}`, `{"webhook_enabled": True}`, `{"webhook_auth": None}`, `{"webhook_auth": {}}`, `{"webhook_auth": {"mode": ""}}`, `{"webhook_auth": {"mode": None}}`: `GenericGateway(config).check_webhook_auth({}, {}, b"")` is True and `GenericGateway(config).check_webhook_auth(None, None, None)` is True.
10. `test_check_webhook_auth_mode_none_ignores_configured_secret`: `g = gateway("none", header_name="X-Signature", query_param="secret")`; `g.check_webhook_auth({"X-Signature": "forged"}, {"secret": "forged"}, BODY)` True; `g.check_webhook_auth({}, {}, b"anything")` True.
11. `test_check_webhook_auth_header_secret`: `g = gateway("header_secret", header_name="X-Webhook-Secret")`: headers `{"x-webhook-secret": SECRET}` → True; `{"X-WEBHOOK-SECRET": SECRET}` → True; `{"X-Webhook-Secret": "wrong"}` → False; `{}` → False (query `{}`, body `BODY` each time). With `GenericGateway({"webhook_auth": {"mode": "header_secret", "header_name": "X-Webhook-Secret", "secret_field": "webhook_secret"}, "credentials": {}})`, headers `{"X-Webhook-Secret": ""}` → False. With the same config but `"credentials": {"webhook_secret": SECRET}` and no `secret_field`, headers `{"X-Webhook-Secret": SECRET}` → False.
12. `test_check_webhook_auth_query_secret`: `g = gateway("query_secret", query_param="secret")`, headers `{}`, body `BODY`: query `{"secret": SECRET}` → True; `{"secret": "wrong"}` → False; `{"Secret": SECRET}` → False; `{}` → False; `None` → False.
13. `test_check_webhook_auth_hmac`: `g = gateway("hmac_sha256", header_name="X-Signature")`: `{"X-Signature": sig()}` with `BODY` → True; `{"x-signature": "  " + sig().upper() + " "}` with `BODY` → True; `{"X-Signature": sig(b"other")}` with `BODY` → False; `{"X-Signature": "sha256=" + sig()}` with `BODY` → False; `{}` with `BODY` → False; `{"X-Signature": sig(b"")}` with raw body `None` → True. `gateway("hmac", header_name="X-Signature")` with `sig()` → True. `gateway("hmac_sha256", header_name="X-Signature", hmac_algo="md5")`: `sig(algo=hashlib.md5)` → True, `sig()` → False. `gateway("hmac_sha256", header_name="X-Signature", hmac_algo="no-such-algo")` with `sig()` → True (falls back to SHA-256). `GenericGateway({"webhook_auth": {"mode": "hmac_sha256", "header_name": "X-Signature", "secret_field": "webhook_secret"}, "credentials": {}})` with `{"X-Signature": sig(secret="")}` → False.
14. `test_check_webhook_auth_unknown_mode_rejects_and_logs(caplog)`: with `caplog.at_level(logging.WARNING, logger="payment_engine")`: `gateway("HMAC_SHA256", header_name="X-Signature")` with `sig()` → False; `gateway("None")` with `{}` → False; `gateway("signature")` with `{}` → False. Exactly three WARNING records from logger `payment_engine`, whose `getMessage()` values are, in order, `"حالت webhook_auth ناشناخته: HMAC_SHA256"`, `"حالت webhook_auth ناشناخته: None"`, `"حالت webhook_auth ناشناخته: signature"`.
15. `test_parse_webhook_without_amount_path_lets_amount_check_pass`: `mapping = {"txn_id_path": "txn_id", "status_path": "status", "success_values": ["paid"]}`; `GenericGateway({"webhook_mapping": mapping}).parse_webhook({"txn_id": "T-1", "status": "paid", "amount": 1}, {})` equals `{"txn_id": "T-1", "status_value": "paid", "success": True, "amount": None}`, and `amounts_match(None, EXPECTED)` on that `amount` is True. With `{**mapping, "amount_path": "amount"}` the same body gives `"amount": 1`, and `amounts_match(1, EXPECTED)` is False. With `{"txn_id_path": "txn_id", "status_path": "status"}` (no `success_values`) the same body gives `"success": None`.
