## Rules

1. "Composite purchases/renewals create no purchase-based referral rewards, referring-reseller commissions, deferred payout promises or first-purchase referral consumption. Existing invite-only rewards/relationships/earned wallet credit and later qualifying legacy purchase eligibility remain." [spec NG-05]
2. "Existing shop-account blocks MUST remain interaction/eligibility restrictions, not implicit service suspension, URL invalidation, replacement, cancellation or refund. Unblocking clears no service restriction. Staff block permission does not confer owner service powers." [spec FR-063]
3. Characterization: pin what the code does today, including these weak spots. Don't fix or skip them: disabled referral settings leave the first-purchase flag unconsumed (case 3); a zero reward still consumes it and counts toward the cap (cases 4, 5); the inline-reseller commission is paid on every call, whatever the referral settings (case 6); the invite bonus is paid again when called again for the same invitee (case 7); the free-config prize returns a product id nobody checked (case 8); the middleware renames a blocked user before refusing (case 11); the Mini App test claim and the bot test handler don't check the block (cases 15, 16); blocked users still earn and pay referral rewards (case 17); blocking an unknown user is logged as done (case 14).
4. "A test fails if it opens a socket to anything other than loopback, looks up a host name other than `localhost`, or opens a SQLite file outside pytest's temporary directory for the run (use `tmp_path`)." [tests/README.md] Every database goes under `tmp_path`.
5. Fake only these: `blocked_user.Message` → `FakeMessage` and `blocked_user.CallbackQuery` → `FakeCallbackQuery` with `monkeypatch.setattr` (cases 10, 11); the bot as `RecordingBot`; in cases 10 and 11 one sub-step replaces the instance method `db.add_or_update_user` with a function that raises `RuntimeError("synthetic")`. Everything else runs for real: `database.py`, the middleware, the handlers, the web panel and the Mini App.
6. Write the zero-width non-joiner as the escape `\u200c` and the emoji variation selector as `\ufe0f`, never as raw characters. Copy the constants below exactly.
7. Exactly 17 test functions, no `parametrize`, each preceded by a `# Case N` comment, as in `test_admin_auth.py`.
