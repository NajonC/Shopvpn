## Interfaces

Implement in `composite/service.py`:
- Frozen dataclass `Principal(identity_domain: str, authenticated_actor_id: int, tenant_installation_id: str, role: str, authenticated_interface: str)`.
- `AuthorityError(Exception)`: `.code` and `str(error)` equal only the supplied constant code. Helpers below use only `unauthenticated`, `forbidden`, `not_found`; never include target/payload/identity/private values.
- `telegram_principal(event, *, tenant_installation_id: str) -> Principal`: caller has already authenticated Telegram transport. Use only event.from_user.id (message or callback). Missing sender/id raises unauthenticated, with no fallback to message sender, data, user_id or bearer. Return `Principal("telegram", actor, tenant_installation_id, "customer", "telegram")`. Preserve trusted installation argument. Reseller/discount metadata does not alter identity.
- `authorize_customer_resource(principal: Principal, *, main_installation_id: str, resource_tenant_installation_id: str, customer_telegram_id: int) -> None`: trusted configuration and persisted resource metadata. Require identity_domain=`telegram`, authenticated_interface=`telegram`, role=`customer`, principal installation=main installation, else forbidden. Require resource installation=principal installation and resource customer=principal actor, else opaque not_found. No DB/log/network effects.
- `web_principal(admin, *, main_installation_id: str, main_owner_web_admin_id: int) -> Principal`: takes only the mapping already produced by real get_current_admin (caller precondition, no request/body parsing). Require tenant exactly empty string, role exactly owner, ABSENT `mobile_token_id` key, both admin id and mapped owner strict built-in int (bool/string invalid), mapped owner >0 and equality of those IDs. Otherwise forbidden. Return `Principal("web_admin", admin["id"], main_installation_id, "owner", "web")`. No implicit Telegram owner fallback, permissive tenant alias or staff permissions fallback.
- Frozen dataclass `CommandContext`: required `request_key: str`; `observed_resource_revision: int | None = None`; `audit_reason: str | None = None` with `repr=False` (retained privately, never logged).
- Frozen dataclass `CommandResult`: required `operation_id: str`, `state: str`, `original_clock_at: int`; optional `subscription_id: str | None = None`, `checkout_id: str | None = None`, `financial_state: str | None = None`, `availability_state: str | None = None`, `desired_restrictions: tuple[str, ...] = ()`, `confirmed_remote_summary: str = ""`, `target_at: int | None = None`, `escalation_at: int | None = None`, `qualified_usage: Mapping[str, object] | None = None`, `retry_same_operation: bool = False`, `public_reason: str = ""`, `support_action: str = ""`. Standard dataclass constructor; no arbitrary payload kwargs or URL/audit-reason field. Preserve values and original epoch-millisecond clocks, never infer confirmed state.

Record shapes are routine Python interface choices, not new business validation. Document that result summary/usage/reason/support are caller-sanitized public structured values; never pass raw payloads/secrets/private context. Records do not heuristically sanitize strings, deep-freeze nested usage, authorize business commands, generate URLs or implement eligibility. Later commands must apply shop eligibility, retrieve persisted ownership and call guards before effects. Adapters authenticate transport before constructing principal; never deserialize Principal from client JSON. No production call sites added here.
