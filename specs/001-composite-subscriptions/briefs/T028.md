## Goal

The tests in this packet characterize existing code: they snapshot the Telegram contracts a later composite feature must not break — the callback-data strings in `keyboards.py`, the admin-panel and button-registry keys, the `states.py` state names, what `fsm_storage.SQLiteStorage` stores, and how `/start` deep-link parameters are parsed. Later tasks import the snapshot constants from this file to prove a new `cmp:` callback namespace collides with nothing. You write no production code; every test must pass against today's code. Everything goes in one new test file.

## What already exists

Do not change any of these.

- `handlers_user.py` `cmd_start` (386–472), found with `find_handler(router, "message", "cmd_start")`, called as `await handler(message, state, bot)`. **Helpers**:
- `_callback_literals(path) -> tuple[frozenset, frozenset, int]`: parse `REPO_ROOT / path` (UTF-8) with `ast.parse`; for every `ast.keyword` with `arg == "callback_data"` anywhere in the tree (`ast.walk`): an `ast.Constant` str value goes into `exact`; an `ast.JoinedStr` whose first `values[0]` is an `ast.Constant` puts that constant's text into `prefixes`; anything else (a name, a call, an f-string starting with a placeholder) adds 1 to `unresolved`. Returns `(frozenset(exact), frozenset(prefixes), unresolved)`.
- `_state_names()`: every class `c` in `vars(states).values()` with `isinstance(c, type) and issubclass(c, StatesGroup) and c is not StatesGroup and c.__module__ == "states"`; returns `(number_of_groups, sorted(s.state for c in groups for s in c.__states__))`.

- `_user_row(db, tg_id)`: `with db._get_conn() as conn: return tuple(conn.execute("SELECT owner_reseller_id, referred_by, acquisition_source, force_join_exempt FROM users WHERE telegram_id=?", (tg_id,)).fetchone())`.
