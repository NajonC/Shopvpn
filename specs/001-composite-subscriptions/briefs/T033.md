## Goal

Implement `composite/repository.py`: the one primitive every later composite command uses to write the main SQLite file. Each command is one short `BEGIN IMMEDIATE` transaction on the repository's own dedicated connection, run on one worker thread so the asyncio event loop never blocks. A busy database surfaces as a typed error after bounded retries, and a failed `COMMIT` is never retried: the caller queries the command's unique effect key instead. The tests already exist and fail only because the module is still empty; make all 31 pass.

## Interfaces

The contract, word for word from the test module's docstring [T032]:

> - ``BUSY_TIMEOUT_S = 1.0`` and ``BUSY_RETRIES = 3``.
> - ``EffectKey(table, column, value)``: a frozen dataclass naming one row by a unique key column.
> - ``Repository(path, *, busy_timeout_s=BUSY_TIMEOUT_S, busy_retries=BUSY_RETRIES, crash=None, connect=None)``. The constructor touches no file. All database work runs on the repository's own single worker thread, on one dedicated connection it opens there on first use by calling ``connect(str(path), **options)`` with ``isolation_level=None`` among the options; ``connect=None`` means ``sqlite3.connect`` looked up at call time. On opening it sets ``journal_mode=WAL``, ``foreign_keys=ON`` and ``synchronous=FULL`` and reads back those three and ``busy_timeout`` (``busy_timeout_s`` in milliseconds); any other value closes the connection and raises ``PragmaMismatch``.
> - ``await run(work, *, effect=None)``: ``BEGIN IMMEDIATE``, then ``work(connection)``, ``crash("before commit")``, ``connection.execute("COMMIT")``, ``crash("after commit")``, and returns ``work``'s result. A busy ``BEGIN IMMEDIATE`` is tried again up to ``busy_retries`` times, then ``RepositoryBusy`` (``attempts``) is raised and ``work`` is never called. Any exception from ``work`` or from the hook before ``COMMIT`` rolls back and propagates unchanged. An awaitable result is closed, rolled back and refused with ``TypeError``. If ``work`` ended the transaction itself, ``TransactionOwnershipError``. If ``COMMIT`` raises, the connection is closed and ``IndeterminateCommit`` (``effect``; the original error as ``__cause__``) is raised; neither ``work`` nor ``COMMIT`` is repeated, and the next ``run`` opens a new connection.
> - ``await query_effect(key)``: the row whose ``key.column`` equals ``key.value`` as a column-name dict, or ``None``, read outside any write transaction and never through a connection whose ``COMMIT`` failed. ``ValueError`` when the table or column is not a plain identifier (``[A-Za-z_][A-Za-z0-9_]*``), or the column is not by itself the table's primary key or a non-partial unique index.
> - ``await close()``.
> - Errors: ``RepositoryError`` and its subclasses ``RepositoryBusy``, ``IndeterminateCommit``, ``PragmaMismatch`` (``pragma``, ``expected``, ``actual``) and ``TransactionOwnershipError``.

How to build it (these settle every point the contract leaves open):

1. **Types.** `@dataclass(frozen=True) class EffectKey: table: str; column: str; value: object`. `class RepositoryError(Exception)`. `RepositoryBusy(attempts: int)` keeps `.attempts`, message `f"database stayed busy after {attempts} attempts"`. `IndeterminateCommit(effect: EffectKey | None)` keeps `.effect`, message `"COMMIT failed; its outcome is unknown until the effect key is queried"`. `PragmaMismatch(pragma: str, expected: object, actual: object)` keeps all three, message `f"PRAGMA {pragma} reads {actual!r}, expected {expected!r}"`. `TransactionOwnershipError`, message `"work ended the repository's transaction itself"`. No message contains an effect value or SQL parameter.
2. **Constructor.** Store `os.fspath(path)` (`TypeError` if that isn't a `str`). `busy_timeout_s`: an `int` or `float`, not `bool` (else `TypeError`), finite (`math.isfinite`), with `round(busy_timeout_s * 1000) >= 1` (else `ValueError`); keep `self._busy_timeout_ms = round(busy_timeout_s * 1000)`. `busy_retries`: an `int`, not `bool` (else `TypeError`), `>= 0` (else `ValueError`). Create `concurrent.futures.ThreadPoolExecutor(max_workers=1, thread_name_prefix="composite-repository")`; it starts no thread until first use. No connection, no file access.
3. **Worker only.** `run`, `query_effect` and `close` each submit one synchronous function with `asyncio.get_running_loop().run_in_executor(self._executor, …)` and await it. Only that worker thread ever touches the connection attribute, so no lock is needed and `check_same_thread` stays at its default. A `Repository` that has been closed raises `RepositoryError("repository is closed")` from `run` and `query_effect`; a second `close()` does nothing.
4. **Opening** (on the worker, when the connection attribute is `None`). Call `(self._connect or sqlite3.connect)(self._database, isolation_level=None, timeout=busy_timeout_s)`. The attribute `sqlite3.connect` must be read at this moment, never bound at import or construction, or the network guard in child processes is bypassed. Pass no other options; the tests add `factory=` themselves. Leave `row_factory` unset. Then execute `PRAGMA busy_timeout = <ms>`, `PRAGMA journal_mode = WAL`, `PRAGMA foreign_keys = ON` and `PRAGMA synchronous = FULL`, and read back, in this order, `journal_mode` expecting `"wal"`, `foreign_keys` expecting `1`, `synchronous` expecting `2` and `busy_timeout` expecting `<ms>`, each as `execute("PRAGMA <name>").fetchone()[0]` compared unchanged. Raise `PragmaMismatch` on the first difference. If anything in this step raises, close the new connection (ignoring errors from the close), keep the attribute `None` and let the error propagate. For `":memory:"` this gives `PragmaMismatch("journal_mode", "wal", "memory")` on every call.
5. **`run(work, *, effect=None)`** (on the worker). `effect` must be an `EffectKey` or `None` (else `TypeError`, before any database work). Open if needed. Then try `execute("BEGIN IMMEDIATE")` up to `busy_retries + 1` times in total, with no extra sleep: the connection's busy timeout is the wait. An `sqlite3.OperationalError` is busy when `(exc.sqlite_errorcode & 0xFF) == sqlite3.SQLITE_BUSY`. After the last busy attempt raise `RepositoryBusy(busy_retries + 1)` from the last busy error. Other errors propagate unchanged. Then:
   - call `result = work(connection)`. On any `BaseException` from it: roll back, then re-raise with a bare `raise` so the very same object propagates;
   - if `inspect.isawaitable(result)`: call its `close()` if it has a callable one, roll back, raise `TypeError("work must be a plain function; it returned an awaitable")`;
   - if `not connection.in_transaction`: raise `TransactionOwnershipError()` (nothing to roll back; the connection stays open);
   - if `crash` is not `None`, call `crash("before commit")`; on any `BaseException` roll back and re-raise it unchanged;
   - `connection.execute("COMMIT")`. It must be this call, once, never `connection.commit()`. On any `BaseException` from it: best-effort `connection.rollback()` (a no-op if the COMMIT landed), then `connection.close()`, ignoring errors from both; set the attribute to `None`; raise `IndeterminateCommit(effect)` from the COMMIT error;
   - if `crash` is not `None`, call `crash("after commit")`, letting anything it raises propagate (the commit stands);
   - return `result`.

   "Roll back" means: if `connection.in_transaction`, `connection.execute("ROLLBACK")`; if that raises, close the connection, ignoring errors, and set the attribute to `None`. The original exception still propagates, not the rollback error. No step may call `work` or `COMMIT` a second time.
6. **`query_effect(key)`.** `key` must be an `EffectKey` (else `TypeError`). `key.table` and `key.column` must each be a `str` and match `re.fullmatch(r"[A-Za-z_][A-Za-z0-9_]*", …)`, else `ValueError`, checked before any database work. On the worker (open if needed; the connection is never inside a transaction between commands), the column qualifies when either:
   - `SELECT name FROM pragma_table_info(?)` filtered to `pk > 0` returns exactly one row, equal to `key.column`; or
   - a row of `SELECT name, "unique", partial FROM pragma_index_list(?)` has `unique == 1` and `partial == 0`, and `SELECT name FROM pragma_index_info(?)` for that index name returns exactly one row, equal to `key.column`.

   Bind the table and index names as parameters. Compare names exactly. A missing table gives no rows, so `ValueError` too, never `sqlite3.OperationalError`. Then `cursor = execute(f'SELECT * FROM "{table}" WHERE "{column}" = ?', (key.value,))` (safe: both names passed the identifier check). Return `dict(zip((d[0] for d in cursor.description), row))` for the first row, or `None`. No write, no `BEGIN`, no busy retry loop.
7. **`close()`.** Mark closed; on the worker, close the connection if there is one (ignoring errors) and set it to `None`; then `self._executor.shutdown(wait=True)`. It never opens a connection, so a `Repository` that was never used leaves no file behind.
8. **Docstrings.** Module docstring: one paragraph saying `work` must be a fast synchronous function doing local SQL only, never network I/O or awaiting, because it runs inside the write transaction. Short docstrings on the public names, in the style of `tests/_harness/crash.py`. English only. No logging and no prints.
